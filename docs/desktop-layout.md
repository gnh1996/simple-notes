# 桌面端布局与文档工作台设计（本地优先）

> **状态：v2.3 标签栏保存状态去噪已实现（2026-11-25：已保存不再显示绿勾、未保存为橙色实心圆点）；v2.2 编辑区密度与专注模式已实现（2026-11-25；文档头压成一行、编辑器去掉外层上下留白、桌面端精简单行工具栏、字数只在状态栏、宽度模式限宽 / 全宽、专注模式 `Ctrl+Shift+F`；Windows 实测回归通过）；v1.6 标签栏视觉编码；v2.1 文档术语统一（服务端 → 云端）**
> 范围：桌面端主窗口布局、资料库侧栏、多标签文档区、起始页、快速打开、统一文档界面、启动顺序与状态呈现
> 关联：`docs/desktop-local-file.md`（临时编辑 / 本地笔记 / 纳入管理）、`docs/desktop-sync.md`（scope / outbox / 冲突）、`docs/content-model.md`（note 字段）
> 非目标（v1）：多窗口、并排分屏、文件树 / 工作区、每标签独立撤销历史、右侧检查器、源文件双向绑定、全文搜索

## 0. 决策摘要

| 决策点 | 结论 |
| --- | --- |
| 主布局 | **默认编辑态：侧栏收起，正文占满窗口**；顶栏 44px + 标签栏 36px + 状态栏 26px |
| 文档头 | **一行约 45px**：标题 + 来源徽标 + 文件夹（笔记）+ 时间 + 保存 / ⋯（文章另有发布状态）；路径与完整时间走 tooltip，云端版本走状态栏 |
| 编辑区留白 | 只保留 Vditor 自带 10px；外层不再叠加 `py-4` |
| 编辑器工具栏 | 桌面端**精简单行集合**（≥约 480px 不换行）；不做两行工具栏；字数只在状态栏显示一次 |
| 宽度模式 | `限宽`（960px，默认）/ `全宽`，账户菜单切换，写入 `ui_state.editor_width_mode` |
| 专注模式 | `Ctrl+Shift+F`：隐藏顶栏 / 标签栏 / 状态栏 / 文档头 / 工具栏；`Esc` 退出；不记忆 |
| 资料库 | `Ctrl+B` / 顶栏 `☰` 打开，**推挤式常驻**；再次点击收起 |
| 资料库内容 | **保留独立文件夹栏**（160px）+ 列表（280px）；文件夹为**树形**（本地 / 云端两棵独立树，最深 5 级，v2.0） |
| 资料来源 | 列表页签固定为 **最近文件 / 本地 / 云端**；未登录隐藏「云端」；默认「本地」；**不提供「全部」混合视图** |
| 侧栏尺寸 | 默认 **440px**，可拖宽 380–520；宽度记忆；**开关状态不记忆**（每次启动收起） |
| 窄窗 | 窗口 <1024px 时资料库降级为浮层，避免正文被压到不可用 |
| 多标签 | **支持**：文件 / 本地笔记 / 云端笔记统一进标签栏；同一文档只保留一个标签 |
| 编辑器实例 | **单实例**：切标签只换内容；不挂多个 Vditor |
| 撤销栈 | 切标签清空撤销栈（单编辑器代价）；v1 不保留每标签撤销历史 |
| 标签数量 | 上限 **12**；超过时提示先关闭，不自动关闭 |
| 标签恢复 | 恢复标签顺序与当前标签；文件标签只存路径，**激活时再读盘**；不存正文 |
| 未保存 | 每个文件标签独立 dirty；**切换标签不弹窗**；关闭 / 退出时处理 |
| 退出 | 多个未保存文件标签 → 汇总对话框（全部保存 / 全部放弃 / 取消） |
| 导航 | 顶栏 `☰` + **`Ctrl+K` 快速打开**（本期做）+ 起始页最近列表 |
| 启动 | 恢复上次标签；云端标签先读缓存，文件标签懒加载；无有效标签进起始页 |
| 新建 | 默认落 `scope='local'`；下拉提供「新建到云端…」（需登录） |
| 网络 | 先本地后网络：首屏只读 SQLite；已登录再后台同步，不阻塞编辑 |
| 文档模型 | `file \| localNote \| serverNote` 统一为 `DocumentTab`；活动标签派生 `ActiveDocument` |
| 文件保存 | 保持显式保存（`Ctrl+S` / 保存按钮），不自动写盘 |
| 本地 / 云端笔记 | 800ms 防抖自动存本地；云端再后台推送 |
| 窗口标题 | `当前标签标题 — Simple Notes`，任一标签未保存时加 `*` |
| 专注模式 | **v1 不做**（顶栏 / 状态栏保留）；后续可加「隐藏状态栏」 |
| 多窗口 | **v1 不做**（每窗口一套 WebView 进程树，内存不可接受） |

## 1. 目标与非目标

### 1.1 目标

1. 打开应用即进入写作面：默认没有侧栏，编辑器占满可用宽度。
2. 本地文件、本地笔记、云端笔记共用**一套文档界面与标签栏**，来源只是文档属性。
3. 可以同时打开多个文件 / 笔记，切换不丢未保存内容，也不反复弹保存框。
4. 找文档仍然方便：侧栏可随时打开，`Ctrl+K` 快速打开兜底。
5. 启动不被网络阻塞：先展示本地内容，再后台同步；离线不是错误态。
6. 不突破现有内存预算：单编辑器实例、标签只存内容字符串、编辑器懒加载。

### 1.2 非目标（v1）

- 多窗口、并排分屏、标签拖出成新窗口；
- 打开目录 / 工作区 / 文件树；
- 每标签独立 Vditor 实例、每标签独立撤销历史；
- 源文件与笔记双向同步、文件重命名跟随；
- 全文搜索（快速打开只匹配标题 / 文件名 / 路径）；
- 右侧大纲 / 属性检查器；
- 发布 / 下架（仍只在 admin）；
- 侧栏固定 / 浮动切换（专注模式与宽度模式已在 v2.2 实现，见 §2.7）。

## 2. 布局

### 2.1 固定区域

| 区域 | 高度 | 职责 |
| --- | --- | --- |
| 顶栏 | 44px | 资料库开关、快速打开、新建、同步状态、账户 |
| 标签栏 | 36px | 打开的文档标签；有标签时才显示 |
| 主区 | 自适应 | 资料库侧栏（可选）+ 文档视图 / 起始页 |
| 状态栏 | 26px | 当前标签的保存状态、待同步、字数、来源细节、在线状态 |

### 2.2 编辑态（默认）

```text
┌───────────────────────────────────────────────────────────────────────┐
│ ☰  Simple Notes     ⌕ 快速打开 Ctrl+K      + 新建 ▾   ⟳ 2  ● 本地  ▾ │ 44
├───────────────────────────────────────────────────────────────────────┤
│ ● 未命名 ×  │ ● todo.md ×  │ ● 周报 ⟳ ×  │                        +  │ 36
├───────────────────────────────────────────────────────────────────────┤
│ 未命名            本地  未分类  11/25 10:32      保存到文件   ⋯       │ 45
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│            Vditor 编辑器（正文列 max-width 960，居中）                  │
│                                                                       │
├───────────────────────────────────────────────────────────────────────┤
│ 已保存到本地 10:32 · 1,204 字 · 本地文件 / 未分类 · 离线               │ 26
└───────────────────────────────────────────────────────────────────────┘
```

- 顶栏左侧 `☰` 打开资料库；`⌕` 打开快速打开；`+ 新建` 是主按钮 + 下拉。
- 标签栏只在有标签时显示；最右侧 `+` 新建本地笔记标签。
- 未登录时右上角显示「本地」+「登录」；登录后显示账号，点击是账户菜单：主题（跟随系统 / 浅色 / 深色）、编辑区宽度（限宽 / 全宽）、打开日志目录、复制诊断信息、登录 / 退出。
- 同步状态只在顶栏显示一个紧凑入口（转圈 / 待重试数字 / 离线圆点），点击展开小面板：同步索引、重试、登录（未登录时）；退出登录在账户菜单。
- **文档头只有一行**（约 45px）：标题（文件标签为文件名）、来源徽标、文件夹选择（笔记）、更新时间（`md` 以上显示）、`保存到文件`（文件标签）、`⋯`；文章额外内联显示发布状态与「有未发布更改」。路径与完整时间在标题 tooltip / 标签 tooltip，云端版本在状态栏详情。
- 正文列默认 `max-width: 960px` 居中（限宽）；窗口变窄时自动占满；全宽模式见 §2.7.1。
- 文档头与正文同宽；编辑器外层不再叠加上下 padding，左右仍 `px-6`。

### 2.3 资料库（推挤式常驻）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ☰  Simple Notes     ⌕ 快速打开 Ctrl+K      + 新建 ▾   ⟳ 2  ● 本地  ▾        │ 44
├────────────┬──────────────┬──────────────────────────────────────────────────┤
│ 文件夹      │ 筛选当前列表… │ ● 未命名 × │ ● todo.md × │ ● 周报 ⟳ × │     + │ 36
│ 全部笔记 12 ├──────────────┼──────────────────────────────────────────────────┤
│ 未分类  3  │ 今天的想法 本地│  未命名                                    ⋯    │
│ 工作    5  │ 周报       云端│  ─────────────────────────────────────────────   │
│ + 新建     │              │                                                  │
│            │ 待同步 2 重试 │            Vditor 编辑器                          │
├────────────┴──────────────┴──────────────────────────────────────────────────┤
│ 已保存到本地 · 1,204 字 · 本地文件 / 未分类 · 离线                           │ 26
└──────────────────────────────────────────────────────────────────────────────┘
```

- 侧栏默认 440px：文件夹栏 160px + 列表 280px；右侧拖拽手柄可在 380–520 调整宽度。
- 文件夹栏为**树形**：`全部笔记 / 未分类` + 本地文件夹树 + 云端文件夹树（两棵独立树，根为第 1 级、最深 5 级）；行内保留层级「＋」用于快速新建子文件夹，改名 / 删除走右键菜单，避免每行堆按钮。
- 列表顶部是**当前列表的筛选输入**（复用 `NotesService.List` 的 keyword），与 `Ctrl+K` 的全局快速打开区分。
- 列表来源页签：`最近文件 / 本地 / 云端`；未登录时隐藏「云端」，默认落在「本地」。
- 「云端」页签下提供**二级分段控件**：`随手记 / 文章`，不再加「类型」标签；文章没有文件夹语义，选中文章时隐藏文件夹栏并清空文件夹筛选。
- 本地 / 云端是两个库：本地笔记不会自动推送；「最近文件」页签只放最近打开的本地文件，不混入笔记列表。
- 「最近文件」页签不显示 `+` 新建按钮，空态提供「打开 Markdown 文件…」；其他页签的 `+` 仍是新建本地笔记。
- 登录不切换当前页签；退出登录时若停在「云端」则回落「本地」，并关闭云端标签。
- 列表行只保留：标题、来源徽标、时间、冲突 / 待同步小标记；`v17`、发布状态移到文档头或右键菜单。
- 点击列表条目：已打开则聚焦对应标签，未打开则新开标签；侧栏保持展开。
- 侧栏宽度写入 `ui_state`；**开关状态不记忆**，每次启动都是编辑态。

#### 2.3.1 右键菜单

- **关闭 WebView2 默认菜单**（返回 / 刷新 / 另存为 / 打印 / 检查）：窗口启用 `DefaultContextMenuDisabled`，前端统一接管 `contextmenu`，开发构建也不会漏出。
- 文件夹行：展开 / 收起（有子级时）、新建子文件夹、重命名、删除（有子级时禁用并提示）；根级新建用底部「＋ 新建文件夹」或文件夹栏空白处右键。
- 列表条目：打开 / 导出 Markdown / 同步到云端（本地笔记且已登录）/ 删除；「最近文件」条目为打开 / 从最近列表移除。
- 标签：关闭 / 关闭其他 / 关闭右侧 / 关闭全部。
- 文本编辑区与输入框：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选；粘贴经 Go `Clipboard` 读取，不依赖 WebView 剪贴板权限。
- 菜单统一由 `components/ContextMenu.vue` 渲染（Teleport 到 body、贴边、方向键 / Esc），各入口只提供菜单项，不另写一套定位与样式。

### 2.4 起始页

没有有效标签时（首次启动、关闭全部标签、恢复失败），显示全宽起始页，而不是空标签栏。

```text
┌──────────────────────────────────────────────────────────────┐
│ ☰  Simple Notes                        ⌕ 快速打开   + 新建 ▾ │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   写点什么，先存在本地。                                       │
│   [ + 新建本地笔记 ]   [ 打开 Markdown 文件… ]                 │
│                                                              │
│   最近                                                        │
│   todo.md             文件 · ~/notes/todo.md      今天 10:20  │
│   今天的想法           本地 · 未分类               今天 09:12  │
│   周报                 云端 · 工作                10/30        │
│                                                              │
│   登录后可同步到服务器（可选）                     [登录]      │
└──────────────────────────────────────────────────────────────┘
```

- 最近列表混合文件、本地笔记、云端笔记，按最近使用排序，最多 10 条；「打开资料库」进入资料库（默认「本地」页签）。
- 未登录时登录入口是次要操作，不阻挡新建 / 打开。
- 起始页不触发网络请求；已登录的后台同步可以同时进行，但不改变页面结构。

### 2.5 快速打开（`Ctrl+K`）

```text
        ┌──────────────────────────────────────────────┐
        │ ⌕ 搜索标题、文件名或操作…                     │
        │ ──────────────────────────────────────────── │
        │ 最近文件                                      │
        │   todo.md                  文件 · 已打开      │
        │ 本地笔记                                      │
        │   今天的想法               本地 · 未分类      │
        │ 云端笔记                                      │
        │   周报                     云端 · 工作        │
        │ 操作                                          │
        │   新建本地笔记                    Ctrl+N      │
        │   打开 Markdown 文件…             Ctrl+O      │
        │   展开资料库                      Ctrl+B      │
        └──────────────────────────────────────────────┘
```

- 顶栏常驻 `⌕ 快速打开 Ctrl+K`；侧栏收起时它是主要切换入口。
- 宽度约 640px，居中靠上；输入即过滤已加载的标题、文件名、路径，**不发请求**。
- 分组：最近文件 / 本地笔记 / 云端笔记 / 操作；`↑↓` 选择，`Enter` 执行，`Esc` 关闭。
- 已在标签中打开的文档显示「已打开」；`Enter` 聚焦该标签，不再新开。
- v1 只匹配标题 / 文件名 / 路径，不搜正文。
- 与资料库筛选输入互不影响：快速打开用于跳转，侧栏输入用于筛选当前列表。

### 2.6 响应式

| 窗口宽度 | 资料库 | 说明 |
| --- | --- | --- |
| ≥1024px | 推挤式常驻 | 默认收起；打开后占 440px，正文约 560–1000px |
| 900–1023px | 浮层抽屉 | 推挤会压坏正文；改为 440px 浮层 + 遮罩，选中后关闭 |
| <900px | 不支持 | 窗口最小 900×600 不变（`main.go`） |

- 断点沿用 `useBreakpoint()`（`lg = 1024`），不引入第二套断点。
- 标签栏在窄窗下只做横向滚动，不换行、不隐藏；标签最小宽度 104px。
- 1024px + 440px 资料库时正文列 536px（段落约 29 汉字/行）；精简工具栏约 480px，仍保持**单行**（v2.2）。

### 2.7 编辑区密度（v2.2）

实测基线（Windows 11 / 125% 缩放、DPR 1.25，打开一篇 Markdown，仅统计正文可视区；「→」左侧为 v2.1，右侧为 v2.2）：

| 场景 | 窗口（CSS） | 正文列宽 | 正文可视高 | 可见行数 |
| --- | --- | --- | --- | --- |
| 默认 1180×780，资料库收起 | 1166×743 | 912px | 484 → **557px** | 20 → **23** |
| 默认窗口，资料库展开 | 1166×743 | 738px | 449 → **557px** | 18 → **23**（工具栏不再换行） |
| 1024 宽 + 资料库 | 1024×706 | 596px | 412 → **520px** | 17 → **21** |
| 最小窗口 900×600 | 892×602 | 844px | 343 → **416px** | 14 → **17** |
| 专注模式（默认窗口） | 1166×743 | 912px | 723px | **30** |

- 宽度不是瓶颈（段落 827px ≈ 50 汉字/行，属于偏宽）；**高度是**：v2.1 默认窗口非正文占 38%，其中文档头 85px、外层 `py-4` 32px、两行工具栏 71px 都可回收。
- v2.2 固定规则：
  1. 文档头压成一行（45px），回收 40px；
  2. 编辑器外层只保留左右 `px-6`，回收 32px；
  3. 桌面端工具栏用精简单行集合（约 480px），窄窗不再换第二行，窄窗回收 35px；被移出的项见 §2.7.3；
  4. 字数只在状态栏出现一次，关闭 Vditor 计数器；
  5. 不提高最小窗口（仍 900×600）——以上四项已让最小窗口回到 17 行，配合专注模式可达 22 行。

#### 2.7.1 宽度模式

- `限宽`（默认）：正文列 `max-width: 960px` 居中；`全宽`：正文列占满主区（左右仍 `px-6`）。
- 入口：账户菜单「编辑区宽度」二档；写入 `ui_state.editor_width_mode`，重启保持。
- 默认仍限宽：长行影响阅读与逐行对照；1440px 以上需要更大画布时手动切全宽。
- 全宽只改列宽，不改字号、行高、工具栏与文档头。

#### 2.7.2 专注模式

- 入口：`Ctrl+Shift+F`、文档 `⋯` 菜单「进入专注模式」；退出：`Esc`、`Ctrl+Shift+F`。
- 隐藏：顶栏、标签栏、状态栏、文档头、编辑器工具栏；保留正文与冲突 / 外部修改 / 删除横幅。
- 进入时自动收起资料库；退出不自动展开资料库。进入时顶部居中提示「专注模式 · Esc 退出」，约 2.5 秒淡出。
- 不改变当前标签与内容（滚动位置、光标保持）；切标签仍可用 `Ctrl+Tab`；标签关闭到 0 时自动退出专注。
- **不记忆**开关状态：每次启动都是正常布局（与资料库开关一致）。
- 专注模式下保存、同步、状态提示仍按 §6 在后台进行，只是不可见；`Ctrl+S` 仍有效。
- `Esc` 优先级：先关应用级浮层（右键菜单 / 快速打开 / 对话框），再退出专注；编辑器内 Vditor 自身的 `Esc` 行为不再单独判断（以退出专注为准）。
- 期望收益：默认窗口正文从 554px → 约 723px（约 30 行）。

#### 2.7.3 不保留的工具栏项

| 项 | 结论 | 原因 |
| --- | --- | --- |
| `record`（录音） | 不保留 | Vditor 录音结束后走 `upload`，而桌面端上传只产出图片语法（`docs/desktop-media.md` 只设计图片），WAV 会被写成 `![record*.wav](...)` 破坏正文；另需 WebView2 麦克风权限。要做须先设计音频的存储 / 引用 / 播放。 |
| `outline`（大纲） | 不保留（可另做开关） | 它是 `.vditor-content` 内 250px 的**推挤列**而非浮层：1024px + 资料库（正文 596px）时正文只剩约 346px，与限宽 + 推挤式资料库冲突；右侧大纲也在 v1 非目标内。若要做，应做成独立开关并在窄窗禁用。 |
| `export`（导出） | 不保留 | 桌面端已有 `⋯ → 导出为 Markdown…`（Go 原生保存对话框）。Vditor 的 Markdown / HTML 导出走浏览器 `download()`（Wails 无下载 UI，未验证），PDF 走 iframe + `window.print()`（未验证），导出样式取自 `dist/index.css`，与端内主题不一致。PDF / HTML 导出应走 Go 设计。 |
| `fullscreen` / `preview` / `both` / `info` / `help` | 不保留 | 专注模式（§2.7.2）覆盖全屏诉求；IR 已内联预览；`both` / `help` 面向 Web 端演示，桌面端无入口价值。 |

- 判断标准：**桌面端工具栏只放「改了立刻进正文」的写作能力**；涉及文件落盘、外部设备、额外渲染资源的入口走 `⋯` 菜单（受控的 Go 调用）或专门设计，不放工具栏。

## 3. 多标签

### 3.1 范围与身份

所有文档类型统一进标签栏，不再为临时文件单独做整屏模式。

| 来源 | 标签 key | 标题 | 备注 |
| --- | --- | --- | --- |
| 文件 | `file:<绝对路径>` | 文件名（含 `.md`） | 同一路径只开一个标签 |
| 本地笔记 | `local:<noteId>` | 笔记标题，空则「未命名」 | 归属 `scope='local'` |
| 云端笔记 | `server:<scopeId>:<noteId>` | 笔记标题 | 账号切换时关闭 |

- 同一文档重复打开只聚焦已有标签，不创建副本。
- 文件标签的路径以 Go 返回的解析后路径为准；Windows 下大小写差异属于边界情况，v1 接受。
- 标签顺序 = 打开顺序；v1 不做拖拽重排（L3 可选）。
- 标签上限 **12**；达到上限时提示先关闭，不自动关闭任何标签。

### 3.2 标签状态

```ts
type DocumentRef =
  | { source: 'file'; path: string }
  | { source: 'local'; noteId: string }
  | { source: 'server'; scopeId: string; noteId: string }

interface DocumentTab {
  key: string
  ref: DocumentRef
  title: string
  content: string
  loaded: boolean              // 文件懒加载 / 云端未缓存时为 false
  dirty: boolean               // 文件未写盘；笔记未落库
  saveState: 'idle' | 'saving' | 'saved' | 'synced' | 'offline' | 'conflict' | 'error' | 'missing'
  scrollTop: number
  // 文件
  path?: string
  name?: string
  hash?: string
  lineEnding?: 'lf' | 'crlf'
  size?: number
  // 笔记
  folderId?: string
  localOnly?: boolean
  remoteVersion?: number
  publishStatus?: string
  hasUnpublishedChanges?: boolean
  error?: string
}
```

- 现有单文档的 `selected / tempFile / dirty / saveState` 收敛为 `tabs: DocumentTab[] + activeKey`，当前文档由活动标签派生。
- 保存定时器按标签 key 管理；非活动标签没有输入，不会产生新的防抖任务。
- 文件标签的 dirty 在切换标签后保留，标签上显示未保存点；笔记标签在切走时 flush 本地。

### 3.3 打开、切换、关闭

**打开**

- 文件：对话框 / 拖拽 / 最近列表 / `Ctrl+O` → 若已打开则聚焦，否则新开标签。
- 笔记：侧栏 / 快速打开 → 若已打开则聚焦；否则 `Notes.Open`（云端优先 `OpenCached`）后新开标签。
- `Ctrl+N` / 顶栏 / 资料库「＋」新建：新建本地笔记标签，并落到当前选中的本地文件夹；若当前活动标签是**空白未命名本地笔记**（标题「未命名」、正文为空、未保存过，且**所属文件夹与本次新建目标一致**），复用它而不是再开一个，并在状态栏提示「当前已是空白笔记」。文件夹不一致时不复用，避免在 A 文件夹点新建却复用了 B 文件夹的空白笔记。
- 纳入管理成功后：用新笔记标签**替换当前文件标签**（保持顺序），文件本身不变。

**切换**

- 切走笔记标签前 flush 本地（800ms 防抖立即执行）。
- 切走文件标签**不弹保存框**：未保存内容留在该标签，标签显示未保存点。
- 切换时保存当前 `scrollTop`；切回后恢复滚动位置。
- 单编辑器实例：`MarkdownEditor` 收到内容变化时调用 `editor.setValue(value, true)`，**清空撤销栈**并重置表格列宽会话态。
- 光标位置 v1 不保证恢复；只保证内容与滚动位置。
- 未加载的文件标签在激活时读取；读取期间显示加载占位；失败时该标签显示错误，其他标签不受影响。

**关闭**

- 文件标签 dirty：弹「保存 / 放弃 / 取消」；保存失败（外部修改 / 文件缺失）时留在该标签并显示横幅。
- 笔记标签：先 flush；云端冲突不阻止关闭，列表行仍保留冲突标记。
- 关闭活动标签后优先激活右侧标签，没有则左侧；没有标签则回到起始页。
- 关闭其他 / 关闭全部：多个 dirty 文件标签使用同一个汇总对话框。
- 中键点击标签可关闭；关闭按钮 hover 才出现，未保存状态图标常驻显示（不因 hover 隐藏）。

### 3.4 退出与未保存

- `SetUnsaved(any)` 的布尔值 = 是否存在 dirty 文件标签或待落库笔记。
- 窗口关闭时：
  1. flush 所有笔记标签；
  2. 收集 dirty 文件标签；
  3. 若有多个，显示汇总对话框：列出文件名 + 「全部保存 / 全部放弃 / 取消 / 逐个处理」；
  4. 「全部保存」按标签顺序保存；任一失败则聚焦该标签、中止退出；
  5. 全部成功 / 放弃后调用 `ConfirmClose()`。
- 关闭单个标签与退出应用使用同一套保存结果处理，不重复实现。
- 崩溃恢复仍不在 v1：未写盘的临时内容不落库，标签恢复只恢复路径。

### 3.5 标签恢复

`ui_state.open_tabs` 保存标签顺序与当前标签：

```json
{
  "tabs": [
    { "source": "file", "path": "C:\\notes\\todo.md", "name": "todo.md" },
    { "source": "local", "id": "..." },
    { "source": "server", "scopeId": "srv:...", "id": "..." }
  ],
  "active": 1
}
```

- 启动时恢复标签顺序与 `active`；最多恢复 12 个。
- 本地笔记：直接读 SQLite；找不到则丢弃该标签。
- 云端笔记：只恢复当前 active scope 的标签；先 `OpenCached`，未缓存则显示「尚未缓存，联网后打开」占位。
- 文件标签：只存路径与文件名，**不存正文、不存 hash**；非活动标签不读盘，激活时再读。
- 活动文件标签在启动时读取磁盘当前内容；跨会话不保留“外部修改”冲突状态（因为未保存内容不会跨会话保留）。
- 文件不存在 / 无权限：标签保留并显示错误，提供「重新选择 / 移除标签」；不自动删除。
- 没有有效标签 → 起始页。

### 3.6 账号切换

- 退出登录：先 flush 云端标签；关闭所有 `server` 标签；`local` 与 `file` 标签保留。
- 云端标签存在未推送修改且 flush 失败：提示「未推送修改仍保存在本地库，退出后将关闭云端标签」；确认后关闭。
- 切换账号 / 服务器：旧 scope 的云端标签全部关闭，不自动打开新账号的标签。
- 本地笔记与文件标签不受账号影响。

### 3.7 标签栏交互

- 标签宽度在 104–200px 之间自适应；标签增多时自动压缩，标题截断并保留 tooltip；仍超出时可横向滚动 / 滚轮滚动，隐藏原生滚动条，切换标签自动滚入视野。
- 左侧**来源徽标**同时用形状 + 颜色编码，不只靠颜色区分：文件=琥珀色文档图标（显式保存到磁盘）、本地=紫色数据库图标（只在本机库）、云端=中性灰云图标（本地优先 + 后台同步）。徽标底色为对应色调的 10% 淡底。
- 右侧**保存状态**只标记「异常 / 进行中」，**已保存是默认态、不画图标**（避免整排绿勾噪音，保存成功的确认由状态栏文案给出）：实心橙点=有未保存内容（文件未写盘 / 笔记未落库 / 未推送）、转圈=保存中或载入中、红色圆点=云端冲突、红色 `!`=保存失败或标签加载失败、琥珀 `!`=文件被外部修改、空心圈=标签尚未载入（懒加载的文件标签）；保存完成后图标消失。
- 状态图标与关闭按钮各占固定宽度，不随状态切换跳动；关闭按钮 hover 才出现（未保存内容不因 hover 改变可见性）。
- 标签 tooltip：文件显示完整路径，笔记显示「来源 + 标题」，并附带当前保存状态文案。
- 活动标签使用面板底色 + 2px 品牌色下边框；非活动标签低对比，hover 提亮。
- 标签栏横向滚动；滚轮横向滚动；标签过多时用 `Ctrl+1..9` / `Ctrl+Tab` 切换（溢出下拉留待后续）。
- 右键菜单：关闭 / 关闭其他 / 关闭右侧 / 关闭全部；导出 / 管理端发布 / 复制路径留在文档头或列表菜单（v1 不在标签菜单重复）。
- `+` 按钮：新建本地笔记标签。

### 3.8 标签快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Ctrl+1` … `Ctrl+8` | 切到第 1–8 个标签 |
| `Ctrl+9` | 切到最后一个标签 |
| `Ctrl+N` | 新建本地笔记标签 |
| `Ctrl+O` | 打开 Markdown 文件（新标签或聚焦已有） |

## 4. 统一文档模型

### 4.1 三种来源

所有来源共用 `DocumentView`，由能力表决定按钮与状态，不再为临时文件单独写全屏模板。

| 来源 | 身份 | 保存 | 状态文案 | 主要动作 |
| --- | --- | --- | --- | --- |
| 文件 | `path + hash` | 显式 `Ctrl+S` 写回源文件 | 未保存到文件 / 已保存 10:32 | 保存到文件、另存为、纳入管理 |
| 本地笔记 | `note_local(scope=local)` | 800ms 自动存 SQLite | 已保存到本地 10:32 | 同步到云端、导出、删除 |
| 云端笔记 | `note_local(scope=srv)` | 本地先写 + 后台推送 | 已同步 / 同步中 / 离线待同步 / 冲突 | 同步、导出、管理端发布（仅 POST） |

### 4.2 文档头

- **单行**（约 45px）：标题输入（20px，无边框，hover 才出现输入框边界）、来源徽标、文件夹选择（笔记）/ 文件名（文件，截断 + 完整路径 tooltip）、更新时间（`md` 以上）、`保存到文件`、`⋯`。
- 路径、云版本、标签不再各占一行：路径走标题 / 标签 tooltip，云版本与文件夹走状态栏详情；文章仍内联显示发布状态与「有未发布更改」；标签在 `lg` 以上单行截断显示。
- 文件标签显示主按钮 **「保存到文件」**；笔记不显示保存按钮，只显示状态。
- `⋯` 菜单按来源显示：保存 / 另存为 / 纳入管理 / 同步到云端 / 导出 / 管理端发布 / 删除 / 关闭，外加 **进入专注模式**。
- 冲突、远端删除、发布状态横幅放在文档头下方、正文上方，沿用现有交互（不占文档头的高度预算）。

### 4.3 来源视觉

| 来源 | 徽标 | 颜色 |
| --- | --- | --- |
| 文件 | `文件` | 琥珀 |
| 本地笔记 | `本地` | 紫 |
| 云端笔记 | `云端` | 中性 |

- **「本地模式」不再使用琥珀警告色**；未登录是正常状态，不是降级态。
- 绿色只用于「已同步」文字 / 图标，不作为来源色。

## 5. 启动与本地优先

### 5.1 启动顺序

```text
1. AuthService.Current()                    // SQLite，不触网
2. SystemService.Status()                   // SQLite（仅登录时）
3. loadRecent()                             // recent_file
4. 读取 ui_state.open_tabs
5. 恢复标签（最多 12 个）：
   - 本地笔记      → Notes.Open(id)（只读 SQLite）
   - 云端笔记    → OpenCached(id)；有缓存立即渲染，后台 Open 校验
   - 文件          → 只恢复标签元数据；活动标签读取磁盘，非活动懒加载
6. reloadFolders() + loadList()             // SQLite
7. 首屏渲染完成
8. 已登录 → 后台 SyncService.Refresh()      // 不 await；失败只更新同步状态
```

- 首屏**不等待网络**；同步失败不弹错误横幅，只在顶栏 / 状态栏标记离线。
- 云端笔记未缓存且离线：文档区显示「该笔记尚未缓存，联网后打开」+ 重试，不阻塞其他标签。
- 活动标签恢复失败 → 激活下一个有效标签；全部失败 → 起始页。
- `ui_state.open_tabs` 在打开 / 关闭 / 切换 / 排序后防抖写入。

### 5.2 新建

- 主按钮 `+ 新建`：新建 `scope='local'` 的本地笔记标签，标题「未命名」。
- 下拉：
  - 新建本地笔记（默认，`Ctrl+N`）；
  - 新建到云端…（仅登录后可用；沿用现有 `Notes.Create` 与 outbox）；
  - 打开 Markdown 文件…（`Ctrl+O`）；
  - 打开并纳入管理…（现有临时编辑流程）。
- 登录状态下**不默认写云端**；避免随手记触发网络写入。

### 5.3 切换与关闭

- 切换标签：笔记 flush 本地；文件保留未保存内容；不弹保存框。
- `Ctrl+W` / 关闭标签：按 §3.3 处理。
- 窗口关闭沿用现有 Go `WindowClosing` 拦截与前端确认，按 §3.4 汇总处理。
- 只保留一个 Vditor 实例；切换标签只换内容，不新开编辑器。

## 6. 保存与状态语义

| 状态 | 文件标签 | 本地笔记标签 | 云端笔记标签 |
| --- | --- | --- | --- |
| 未保存 | 未保存到文件（琥珀） | — | — |
| 已保存 | 已保存 10:32 | 已保存到本地 10:32 | 已保存本地 · 同步中 |
| 已同步 | — | — | 已同步 10:32 |
| 离线 | 保存仍写盘；外部修改提示 | 已保存到本地 | 离线待同步（琥珀） |
| 冲突 | — | — | 冲突（红）+ 横幅 |
| 外部修改 / 删除 | 覆盖 / 另存为 / 重新加载 | — | 远端删除横幅 |

- `Ctrl+S`：文件写回；笔记立即 flush 本地并触发推送。
- 文件保存仍是显式行为，不自动写盘；hash 校验、原子写入、换行风格保持不变。
- 本地 / 云端笔记继续 800ms 防抖自动保存；云端推送沿用 `version` CAS 与 409 冲突流程。
- 标签上的状态图标表示该标签自身；状态栏显示活动标签的保存状态；顶栏同步入口显示全局 outbox / 同步状态。三者不混用。

## 7. 顶栏与状态栏

### 7.1 顶栏

| 区域 | 内容 |
| --- | --- |
| 左 | `☰` 资料库（`Ctrl+B`）、`Simple Notes` |
| 中 | `⌕ 快速打开 Ctrl+K`（窗口变窄时收缩为图标） |
| 右 | `+ 新建 ▾`、同步入口、账户 / 登录 |

- 同步入口：转圈 = 同步中；数字 = 待重试；圆点 = 离线；绿色对勾 = 已同步（短暂）。
- 点击同步入口展开小面板：同步索引、重试、登录（未登录时）；服务器地址与退出登录在账户菜单。
- 账户菜单含主题三档：跟随系统 / 浅色 / 深色。默认跟随系统，手动选择写入 localStorage `sn.desktop.theme`；未登录的本地模式也可切换。`index.html` 内联脚本按同一键值在首帧前应用，避免闪白；Vditor 编辑器主题随当前明暗联动。Windows 下原生标题栏 / 边框通过 `System.SetWindowTheme` 调 DWM 同步（macOS / Linux 暂不处理）。
- 账户菜单还含**编辑区宽度**（限宽 / 全宽，§2.7.1），写入 `ui_state.editor_width_mode`。

### 7.2 状态栏

| 区域 | 内容 |
| --- | --- |
| 左 | 活动标签保存状态、待同步项 + 重试、提示（短暂）/ 错误（保留到下一次操作） |
| 中 | 字数（可选，按活动标签正文计算） |
| 右 | 文件：UTF-8 / LF / 大小；笔记：文件夹；云端：版本；在线 / 离线；账号昵称；未登录时只显示一个「本地模式」 |

- 不再显示数据库路径；移动到「关于 / 设置」（后续）。
- **「本地模式」每处只出现一次**：状态栏右侧只在未登录时显示一次；不再重复展示「本地 SQLite · 不连接服务器」等介质信息，未打开标签时左侧保存状态留空。
- 网络失败不进入红色错误区，只改变同步状态。
- 错误只显示短句，完整错误链放在「详情」弹层（见 `docs/desktop-diagnostics.md`）；详情可复制 / 打开日志目录。

## 10. Go 与本地数据改动

### 10.1 新增 `ui_state`

桌面端 SQLite，`CREATE TABLE IF NOT EXISTS`，不涉及 Flyway：

```sql
create table if not exists ui_state (
    key   text primary key,
    value text not null
);
```

| key | 值 | 说明 |
| --- | --- | --- |
| `open_tabs` | §3.5 的 JSON | 标签顺序 + active；文件只存路径 / 名称 |
| `sidebar_width` | `440` | 资料库宽度 |
| `editor_width_mode` | `limited / full` | 正文列宽模式（v2.2 起真正生效，默认 `limited`） |

- 不存侧栏开关状态；每次启动收起。
- 不存专注模式；每次启动都是正常布局。
- 不存临时文件正文 / hash；临时内容仍只在内存。

### 10.2 Go service

| 方法 | 职责 |
| --- | --- |
| `store.GetUIState(key)` / `SetUIState(key, value)` | `ui_state` 读写 |
| `system.GetUIState` / `SetUIState` | 暴露给前端 |
| `system.SetTitle(title)` | 更新窗口标题（当前标签 + 未保存 `*`） |
| `notes.OpenCached(id)` | 只读本地缓存，不触网；标签恢复用；未缓存正文时返回索引行（`contentLoaded=false`），由前端显示占位 |
| `notes.Create` 的 `target` | `target='local'` 强制仅本地（登录状态下新建默认本地）；空值沿用旧行为 |

- 不新增后端接口、不改同步协议、不改 `note_local` / `folder_local` / `outbox` 表。
- 改 Go service 签名后执行 `wails3 task bindings`，`bindings/` 随仓库提交。
- `SetUnsaved(any)` 继续使用现有接口，布尔值由标签集合计算。
