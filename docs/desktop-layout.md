# 桌面端布局与文档工作台设计（本地优先）

> **状态：v1.4 已实现（2026-11-03；Windows 构建通过；最近文件前置 / 二级分段控件 GUI 自动验收通过；完整 L4 手工验收待做）**
> 范围：桌面端主窗口布局、资料库侧栏、多标签文档区、起始页、快速打开、统一文档界面、启动顺序与状态呈现
> 关联：`docs/desktop-local-file.md`（临时编辑 / 本地笔记 / 纳入管理）、`docs/desktop-sync.md`（scope / outbox / 冲突）、`docs/content-model.md`（note 字段）
> 非目标（v1）：多窗口、并排分屏、文件树 / 工作区、每标签独立撤销历史、右侧检查器、源文件双向绑定、全文搜索

## 0. 决策摘要

| 决策点 | 结论 |
| --- | --- |
| 主布局 | **默认编辑态：侧栏收起，正文占满窗口**；顶栏 44px + 标签栏 36px + 状态栏 26px |
| 资料库 | `Ctrl+B` / 顶栏 `☰` 打开，**推挤式常驻**；再次点击收起 |
| 资料库内容 | **保留独立文件夹栏**（160px）+ 列表（280px）；文件夹为**树形**（本地 / 云端两棵独立树，最深 5 级，v2.0） |
| 资料来源 | 列表页签固定为 **最近文件 / 本地 / 服务端**；未登录隐藏「服务端」；默认「本地」；**不提供「全部」混合视图** |
| 侧栏尺寸 | 默认 **440px**，可拖宽 380–520；宽度记忆；**开关状态不记忆**（每次启动收起） |
| 窄窗 | 窗口 <1024px 时资料库降级为浮层，避免正文被压到不可用 |
| 多标签 | **支持**：文件 / 本地笔记 / 服务端笔记统一进标签栏；同一文档只保留一个标签 |
| 编辑器实例 | **单实例**：切标签只换内容；不挂多个 Vditor |
| 撤销栈 | 切标签清空撤销栈（单编辑器代价）；v1 不保留每标签撤销历史 |
| 标签数量 | 上限 **12**；超过时提示先关闭，不自动关闭 |
| 标签恢复 | 恢复标签顺序与当前标签；文件标签只存路径，**激活时再读盘**；不存正文 |
| 未保存 | 每个文件标签独立 dirty；**切换标签不弹窗**；关闭 / 退出时处理 |
| 退出 | 多个未保存文件标签 → 汇总对话框（全部保存 / 全部放弃 / 取消） |
| 导航 | 顶栏 `☰` + **`Ctrl+K` 快速打开**（本期做）+ 起始页最近列表 |
| 启动 | 恢复上次标签；服务端标签先读缓存，文件标签懒加载；无有效标签进起始页 |
| 新建 | 默认落 `scope='local'`；下拉提供「新建到服务端…」（需登录） |
| 网络 | 先本地后网络：首屏只读 SQLite；已登录再后台同步，不阻塞编辑 |
| 文档模型 | `file | localNote | serverNote` 统一为 `DocumentTab`；活动标签派生 `ActiveDocument` |
| 文件保存 | 保持显式保存（`Ctrl+S` / 保存按钮），不自动写盘 |
| 本地 / 服务端笔记 | 800ms 防抖自动存本地；服务端再后台推送 |
| 窗口标题 | `当前标签标题 — Simple Notes`，任一标签未保存时加 `*` |
| 专注模式 | **v1 不做**（顶栏 / 状态栏保留）；后续可加「隐藏状态栏」 |
| 多窗口 | **v1 不做**（每窗口一套 WebView 进程树，内存不可接受） |

## 1. 目标与非目标

### 1.1 目标

1. 打开应用即进入写作面：默认没有侧栏，编辑器占满可用宽度。
2. 本地文件、本地笔记、服务端笔记共用**一套文档界面与标签栏**，来源只是文档属性。
3. 可以同时打开多个文件 / 笔记，切换不丢未保存内容，也不反复弹保存框。
4. 找文档仍然方便：侧栏可随时打开，`Ctrl+K` 快速打开兜底。
5. 启动不被网络阻塞：先展示本地内容，再后台同步；离线不是错误态。
6. 不突破现有内存预算：单编辑器实例、标签只存内容字符串、编辑器懒加载。

### 1.2 非目标（v1）

- 多窗口、并排分屏、标签拖出成新窗口；
- 打开目录 / 工作区 / 文件树；
- 每标签独立 Vditor 实例、每标签独立撤销历史；
- 源文件与笔记双向同步、文件重命名跟随；
- 全文搜索（快速打开只匹配标题 / 文件名 / 路径）；
- 右侧大纲 / 属性检查器；
- 发布 / 下架（仍只在 admin）；
- 专注模式、全宽 / 限宽切换、侧栏固定 / 浮动切换。

## 2. 布局

### 2.1 固定区域

| 区域 | 高度 | 职责 |
| --- | --- | --- |
| 顶栏 | 44px | 资料库开关、快速打开、新建、同步状态、账户 |
| 标签栏 | 36px | 打开的文档标签；有标签时才显示 |
| 主区 | 自适应 | 资料库侧栏（可选）+ 文档视图 / 起始页 |
| 状态栏 | 26px | 当前标签的保存状态、待同步、字数、来源细节、在线状态 |

### 2.2 编辑态（默认）

```text
│ ☰  Simple Notes     ⌕ 快速打开 Ctrl+K      + 新建 ▾   ⟳ 2  ● 本地  ▾ │ 44
├───────────────────────────────────────────────────────────────────────┤
│ ● 未命名 ×  │ ● todo.md ×  │ ● 周报 ⟳ ×  │                        +  │ 36
├───────────────────────────────────────────────────────────────────────┤
│            未命名                                              ⋯       │
│            本地笔记 · 未分类 · 已保存到本地 10:32                       │
│            ───────────────────────────────────────────────            │
│                                                                       │
│            Vditor 编辑器（正文列 max-width 960，居中）                  │
│                                                                       │
│                                                                       │
├───────────────────────────────────────────────────────────────────────┤
│ 已保存到本地 10:32 · 1,204 字 · 本地文件 / 未分类 · 离线               │ 26
└───────────────────────────────────────────────────────────────────────┘
```

- 顶栏左侧 `☰` 打开资料库；`⌕` 打开快速打开；`+ 新建` 是主按钮 + 下拉。
- 标签栏只在有标签时显示；最右侧 `+` 新建本地笔记标签。
- 未登录时右上角显示「本地」+「登录」；登录后显示账号，点击是账户菜单。
- 同步状态只在顶栏显示一个紧凑入口（转圈 / 待重试数字 / 离线圆点），点击展开小面板：同步索引、重试、登录 / 退出。
- 正文列默认 `max-width: 960px` 居中；窗口变窄时自动占满。
- 文档头与正文同宽；标题、来源、保存状态在同一列内。

### 2.3 资料库（推挤式常驻）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ☰  Simple Notes     ⌕ 快速打开 Ctrl+K      + 新建 ▾   ⟳ 2  ● 本地  ▾        │ 44
├────────────┬──────────────┬──────────────────────────────────────────────────┤
│ 文件夹      │ 筛选当前列表… │ ● 未命名 × │ ● todo.md × │ ● 周报 ⟳ × │     + │ 36
│ 全部笔记 12 ├──────────────┼──────────────────────────────────────────────────┤
│ 未分类  3  │ 今天的想法 本地│  未命名                                    ⋯    │
│ 本地文件 2 │ todo.md   文件│  本地笔记 · 未分类 · 已保存到本地 10:32           │
│ 工作    5  │ 周报     服务端│  ─────────────────────────────────────────────   │
│ + 新建     │              │                                                  │
│            │ 待同步 2 重试 │            Vditor 编辑器                          │
├────────────┴──────────────┴──────────────────────────────────────────────────┤
│ 已保存到本地 · 1,204 字 · 本地文件 / 未分类 · 离线                           │ 26
└──────────────────────────────────────────────────────────────────────────────┘
```

- 侧栏默认 440px：文件夹栏 160px + 列表 280px；右侧拖拽手柄可在 380–520 调整宽度。
- 文件夹栏为**树形**：`全部笔记 / 未分类` + 本地文件夹树 + 云端文件夹树（两棵独立树，根为第 1 级、最深 5 级）；行内保留层级「＋」用于快速新建子文件夹，改名 / 删除走右键菜单，避免每行堆按钮。
- 列表顶部是**当前列表的筛选输入**（复用 `NotesService.List` 的 keyword），与 `Ctrl+K` 的全局快速打开区分。
- 列表来源页签：`最近文件 / 本地 / 服务端`；未登录时隐藏「服务端」，默认落在「本地」。
- 「服务端」页签下提供**二级分段控件**：`随手记 / 文章`，不再加「类型」标签；文章没有文件夹语义，选中文章时隐藏文件夹栏并清空文件夹筛选。
- 本地 / 服务端是两个库：本地笔记不会自动推送；「最近文件」页签只放最近打开的本地文件，不混入笔记列表。
- 「最近文件」页签不显示 `+` 新建按钮，空态提供「打开 Markdown 文件…」；其他页签的 `+` 仍是新建本地笔记。
- 登录不切换当前页签；退出登录时若停在「服务端」则回落「本地」，并关闭服务端标签。
- 列表行只保留：标题、来源徽标、时间、冲突 / 待同步小标记；`v17`、发布状态移到文档头或右键菜单。
- 点击列表条目：已打开则聚焦对应标签，未打开则新开标签；侧栏保持展开。
- 侧栏宽度写入 `ui_state`；**开关状态不记忆**，每次启动都是编辑态。

#### 2.3.1 右键菜单

- **关闭 WebView2 默认菜单**（返回 / 刷新 / 另存为 / 打印 / 检查）：窗口启用 `DefaultContextMenuDisabled`，前端统一接管 `contextmenu`，开发构建也不会漏出。
- 文件夹行：展开 / 收起（有子级时）、新建子文件夹、重命名、删除（有子级时禁用并提示）；根级新建用底部「＋ 新建文件夹」或文件夹栏空白处右键。
- 列表条目：打开 / 导出 Markdown / 同步到云端（本地笔记且已登录）/ 删除；「最近文件」条目为打开 / 从最近列表移除。
- 标签：关闭 / 关闭其他 / 关闭右侧 / 关闭全部。
- 文本编辑区与输入框：撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选；粘贴经 Go `Clipboard` 读取，不依赖 WebView 剪贴板权限。
- 菜单统一由 `components/ContextMenu.vue` 渲染（Teleport 到 body、贴边、方向键 / Esc），各入口只提供菜单项，不另写一套定位与样式。

### 2.4 起始页

没有有效标签时（首次启动、关闭全部标签、恢复失败），显示全宽起始页，而不是空标签栏。

```text
┌──────────────────────────────────────────────────────────────┐
│ ☰  Simple Notes                        ⌕ 快速打开   + 新建 ▾ │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   写点什么，先存在本地。                                       │
│   [ + 新建本地笔记 ]   [ 打开 Markdown 文件… ]                 │
│                                                              │
│   最近                                                        │
│   todo.md             文件 · ~/notes/todo.md      今天 10:20  │
│   今天的想法           本地 · 未分类               今天 09:12  │
│   周报                 服务端 · 工作                10/30      │
│                                                              │
│   登录后可同步到服务器（可选）                     [登录]      │
└──────────────────────────────────────────────────────────────┘
```

- 最近列表混合文件、本地笔记、服务端笔记，按最近使用排序，最多 10 条；「打开资料库」进入资料库（默认「本地」页签）。
- 未登录时登录入口是次要操作，不阻挡新建 / 打开。
- 起始页不触发网络请求；已登录的后台同步可以同时进行，但不改变页面结构。

### 2.5 快速打开（`Ctrl+K`）

```text
        ┌──────────────────────────────────────────────┐
        │ ⌕ 搜索标题、文件名或操作…                     │
        │ ──────────────────────────────────────────── │
        │ 最近文件                                      │
        │   todo.md                  文件 · 已打开      │
        │ 本地笔记                                      │
        │   今天的想法               本地 · 未分类      │
        │ 服务端笔记                                    │
        │   周报                     服务端 · 工作      │
        │ 操作                                          │
        │   新建本地笔记                    Ctrl+N      │
        │   打开 Markdown 文件…             Ctrl+O      │
        │   展开资料库                      Ctrl+B      │
        └──────────────────────────────────────────────┘
```

- 顶栏常驻 `⌕ 快速打开 Ctrl+K`；侧栏收起时它是主要切换入口。
- 宽度约 640px，居中靠上；输入即过滤已加载的标题、文件名、路径，**不发请求**。
- 分组：最近文件 / 本地笔记 / 服务端笔记 / 操作；`↑↓` 选择，`Enter` 执行，`Esc` 关闭。
- 已在标签中打开的文档显示「已打开」；`Enter` 聚焦该标签，不再新开。
- v1 只匹配标题 / 文件名 / 路径，不搜正文。
- 与资料库筛选输入互不影响：快速打开用于跳转，侧栏输入用于筛选当前列表。

### 2.6 响应式

| 窗口宽度 | 资料库 | 说明 |
| --- | --- | --- |
| ≥1024px | 推挤式常驻 | 默认收起；打开后占 440px，正文约 560–1000px |
| 900–1023px | 浮层抽屉 | 推挤会压坏正文；改为 440px 浮层 + 遮罩，选中后关闭 |
| <900px | 不支持 | 窗口最小 900×600 不变（`main.go`） |

- 断点沿用 `useBreakpoint()`（`lg = 1024`），不引入第二套断点。
- 标签栏在窄窗下只做横向滚动，不换行、不隐藏；标签最小宽度 120px。

## 3. 多标签

### 3.1 范围与身份

所有文档类型统一进标签栏，不再为临时文件单独做整屏模式。

| 来源 | 标签 key | 标题 | 备注 |
| --- | --- | --- | --- |
| 文件 | `file:<绝对路径>` | 文件名（含 `.md`） | 同一路径只开一个标签 |
| 本地笔记 | `local:<noteId>` | 笔记标题，空则「未命名」 | 归属 `scope='local'` |
| 服务端笔记 | `server:<scopeId>:<noteId>` | 笔记标题 | 账号切换时关闭 |

- 同一文档重复打开只聚焦已有标签，不创建副本。
- 文件标签的路径以 Go 返回的解析后路径为准；Windows 下大小写差异属于边界情况，v1 接受。
- 标签顺序 = 打开顺序；v1 不做拖拽重排（L3 可选）。
- 标签上限 **12**；达到上限时提示先关闭，不自动关闭任何标签。

### 3.2 标签状态

```ts
type DocumentRef =
  | { source: 'file'; path: string }
  | { source: 'local'; noteId: string }
  | { source: 'server'; scopeId: string; noteId: string }

interface DocumentTab {
  key: string
  ref: DocumentRef
  title: string
  content: string
  loaded: boolean              // 文件懒加载 / 服务端未缓存时为 false
  dirty: boolean               // 文件未写盘；笔记未落库
  saveState: 'idle' | 'saving' | 'saved' | 'synced' | 'offline' | 'conflict' | 'error' | 'missing'
  scrollTop: number
  // 文件
  path?: string
  name?: string
  hash?: string
  lineEnding?: 'lf' | 'crlf'
  size?: number
  // 笔记
  folderId?: string
  localOnly?: boolean
  remoteVersion?: number
  publishStatus?: string
  hasUnpublishedChanges?: boolean
  error?: string
}
```

- 现有单文档的 `selected / tempFile / dirty / saveState` 收敛为 `tabs: DocumentTab[] + activeKey`，当前文档由活动标签派生。
- 保存定时器按标签 key 管理；非活动标签没有输入，不会产生新的防抖任务。
- 文件标签的 dirty 在切换标签后保留，标签上显示未保存点；笔记标签在切走时 flush 本地。

### 3.3 打开、切换、关闭

**打开**

- 文件：对话框 / 拖拽 / 最近列表 / `Ctrl+O` → 若已打开则聚焦，否则新开标签。
- 笔记：侧栏 / 快速打开 → 若已打开则聚焦；否则 `Notes.Open`（服务端优先 `OpenCached`）后新开标签。
- `Ctrl+N` / 顶栏新建：新建本地笔记标签；若当前活动标签是**空白未命名本地笔记**（标题「未命名」且正文为空、未保存过），复用它而不是再开一个。
- 纳入管理成功后：用新笔记标签**替换当前文件标签**（保持顺序），文件本身不变。

**切换**

- 切走笔记标签前 flush 本地（800ms 防抖立即执行）。
- 切走文件标签**不弹保存框**：未保存内容留在该标签，标签显示未保存点。
- 切换时保存当前 `scrollTop`；切回后恢复滚动位置。
- 单编辑器实例：`MarkdownEditor` 收到内容变化时调用 `editor.setValue(value, true)`，**清空撤销栈**并重置表格列宽会话态。
- 光标位置 v1 不保证恢复；只保证内容与滚动位置。
- 未加载的文件标签在激活时读取；读取期间显示加载占位；失败时该标签显示错误，其他标签不受影响。

**关闭**

- 文件标签 dirty：弹「保存 / 放弃 / 取消」；保存失败（外部修改 / 文件缺失）时留在该标签并显示横幅。
- 笔记标签：先 flush；服务端冲突不阻止关闭，列表行仍保留冲突标记。
- 关闭活动标签后优先激活右侧标签，没有则左侧；没有标签则回到起始页。
- 关闭其他 / 关闭全部：多个 dirty 文件标签使用同一个汇总对话框。
- 中键点击标签可关闭；关闭按钮只在 hover / 活动标签显示，未保存时先显示未保存点。

### 3.4 退出与未保存

- `SetUnsaved(any)` 的布尔值 = 是否存在 dirty 文件标签或待落库笔记。
- 窗口关闭时：
  1. flush 所有笔记标签；
  2. 收集 dirty 文件标签；
  3. 若有多个，显示汇总对话框：列出文件名 + 「全部保存 / 全部放弃 / 取消 / 逐个处理」；
  4. 「全部保存」按标签顺序保存；任一失败则聚焦该标签、中止退出；
  5. 全部成功 / 放弃后调用 `ConfirmClose()`。
- 关闭单个标签与退出应用使用同一套保存结果处理，不重复实现。
- 崩溃恢复仍不在 v1：未写盘的临时内容不落库，标签恢复只恢复路径。

### 3.5 标签恢复

`ui_state.open_tabs` 保存标签顺序与当前标签：

```json
{
  "tabs": [
    { "source": "file", "path": "C:\\notes\\todo.md", "name": "todo.md" },
    { "source": "local", "id": "..." },
    { "source": "server", "scopeId": "srv:...", "id": "..." }
  ],
  "active": 1
}
```

- 启动时恢复标签顺序与 `active`；最多恢复 12 个。
- 本地笔记：直接读 SQLite；找不到则丢弃该标签。
- 服务端笔记：只恢复当前 active scope 的标签；先 `OpenCached`，未缓存则显示「尚未缓存，联网后打开」占位。
- 文件标签：只存路径与文件名，**不存正文、不存 hash**；非活动标签不读盘，激活时再读。
- 活动文件标签在启动时读取磁盘当前内容；跨会话不保留“外部修改”冲突状态（因为未保存内容不会跨会话保留）。
- 文件不存在 / 无权限：标签保留并显示错误，提供「重新选择 / 移除标签」；不自动删除。
- 没有有效标签 → 起始页。

### 3.6 账号切换

- 退出登录：先 flush 服务端标签；关闭所有 `server` 标签；`local` 与 `file` 标签保留。
- 服务端标签存在未推送修改且 flush 失败：提示「未推送修改仍保存在本地库，退出后将关闭服务端标签」；确认后关闭。
- 切换账号 / 服务器：旧 scope 的服务端标签全部关闭，不自动打开新账号的标签。
- 本地笔记与文件标签不受账号影响。

### 3.7 标签栏交互

- 标签宽度在 88–180px 之间自适应；标签增多时自动压缩，标题截断并保留 tooltip；仍超出时可横向滚动 / 滚轮滚动，隐藏原生滚动条，切换标签自动滚入视野。
- 左侧来源点：文件琥珀、本地紫、服务端中性；冲突时变红。
- 右侧状态：dirty 点 / 同步中转圈 / 冲突红点；hover 时变为关闭按钮。
- 活动标签使用面板底色 + 品牌色下边框；非活动标签低对比。
- 标签栏横向滚动；滚轮横向滚动；标签过多时用 `Ctrl+1..9` / `Ctrl+Tab` 切换（溢出下拉留待后续）。
- 右键菜单：关闭 / 关闭其他 / 关闭右侧 / 关闭全部；导出 / 管理端发布 / 复制路径留在文档头或列表菜单（v1 不在标签菜单重复）。
- `+` 按钮：新建本地笔记标签。

### 3.8 标签快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Ctrl+1` … `Ctrl+8` | 切到第 1–8 个标签 |
| `Ctrl+9` | 切到最后一个标签 |

## 4. 统一文档模型

### 4.1 三种来源

所有来源共用 `DocumentView`，由能力表决定按钮与状态，不再为临时文件单独写全屏模板。

| 来源 | 身份 | 保存 | 状态文案 | 主要动作 |
| --- | --- | --- | --- | --- |
| 文件 | `path + hash` | 显式 `Ctrl+S` 写回源文件 | 未保存到文件 / 已保存 10:32 | 保存到文件、另存为、纳入管理 |
| 本地笔记 | `note_local(scope=local)` | 800ms 自动存 SQLite | 已保存到本地 10:32 | 同步到服务端、导出、删除 |
| 服务端笔记 | `note_local(scope=srv)` | 本地先写 + 后台推送 | 已同步 / 同步中 / 离线待同步 / 冲突 | 同步、导出、管理端发布（仅 POST） |

### 4.2 文档头

- 标题输入（20px，无边框，hover 才出现输入框边界）。
- 元信息行：来源徽标、文件夹选择（笔记）/ 文件路径（文件，截断 + title）、保存状态、最近更新时间。
- 文件标签显示主按钮 **「保存到文件」**；笔记不显示保存按钮，只显示状态。
- `⋯` 菜单按来源显示：另存为 / 纳入管理 / 同步到服务端 / 导出 / 管理端发布 / 删除 / 关闭。
- 冲突、远端删除、发布状态横幅放在文档头下方、正文上方，沿用现有交互。

### 4.3 来源视觉

| 来源 | 徽标 | 颜色 |
| --- | --- | --- |
| 文件 | `文件` | 琥珀 |
| 本地笔记 | `本地` | 紫 |
| 服务端笔记 | `服务端` | 中性 |

- **「本地模式」不再使用琥珀警告色**；未登录是正常状态，不是降级态。
- 绿色只用于「已同步」文字 / 图标，不作为来源色。

## 5. 启动与本地优先

### 5.1 启动顺序

```text
1. AuthService.Current()                    // SQLite，不触网
2. SystemService.Status()                   // SQLite（仅登录时）
3. loadRecent()                             // recent_file
4. 读取 ui_state.open_tabs
5. 恢复标签（最多 12 个）：
   - 本地笔记      → Notes.Open(id)（只读 SQLite）
   - 服务端笔记    → OpenCached(id)；有缓存立即渲染，后台 Open 校验
   - 文件          → 只恢复标签元数据；活动标签读取磁盘，非活动懒加载
6. reloadFolders() + loadList()             // SQLite
7. 首屏渲染完成
8. 已登录 → 后台 SyncService.Refresh()      // 不 await；失败只更新同步状态
```

- 首屏**不等待网络**；同步失败不弹错误横幅，只在顶栏 / 状态栏标记离线。
- 服务端笔记未缓存且离线：文档区显示「该笔记尚未缓存，联网后打开」+ 重试，不阻塞其他标签。
- 活动标签恢复失败 → 激活下一个有效标签；全部失败 → 起始页。
- `ui_state.open_tabs` 在打开 / 关闭 / 切换 / 排序后防抖写入。

### 5.2 新建

- 主按钮 `+ 新建`：新建 `scope='local'` 的本地笔记标签，标题「未命名」。
- 下拉：
  - 新建本地笔记（默认，`Ctrl+N`）；
  - 新建到服务端…（仅登录后可用；沿用现有 `Notes.Create` 与 outbox）；
  - 打开 Markdown 文件…（`Ctrl+O`）；
  - 打开并纳入管理…（现有临时编辑流程）。
- 登录状态下**不默认写服务端**；避免随手记触发网络写入。

### 5.3 切换与关闭

- 切换标签：笔记 flush 本地；文件保留未保存内容；不弹保存框。
- `Ctrl+W` / 关闭标签：按 §3.3 处理。
- 窗口关闭沿用现有 Go `WindowClosing` 拦截与前端确认，按 §3.4 汇总处理。
- 只保留一个 Vditor 实例；切换标签只换内容，不新开编辑器。

## 6. 保存与状态语义

| 状态 | 文件标签 | 本地笔记标签 | 服务端笔记标签 |
| --- | --- | --- | --- |
| 未保存 | 未保存到文件（琥珀） | — | — |
| 已保存 | 已保存 10:32 | 已保存到本地 10:32 | 已保存本地 · 同步中 |
| 已同步 | — | — | 已同步 10:32 |
| 离线 | 保存仍写盘；外部修改提示 | 已保存到本地 | 离线待同步（琥珀） |
| 冲突 | — | — | 冲突（红）+ 横幅 |
| 外部修改 / 删除 | 覆盖 / 另存为 / 重新加载 | — | 远端删除横幅 |

- `Ctrl+S`：文件写回；笔记立即 flush 本地并触发推送。
- 文件保存仍是显式行为，不自动写盘；hash 校验、原子写入、换行风格保持不变。
- 本地 / 服务端笔记继续 800ms 防抖自动保存；服务端推送沿用 `version` CAS 与 409 冲突流程。
- 标签上的状态点表示该标签自身；状态栏显示活动标签的保存状态；顶栏同步入口显示全局 outbox / 同步状态。三者不混用。

## 10. Go 与本地数据改动

### 10.1 新增 `ui_state`

桌面端 SQLite，`CREATE TABLE IF NOT EXISTS`，不涉及 Flyway：

```sql
create table if not exists ui_state (
    key   text primary key,
    value text not null
);
```

| key | 值 | 说明 |
| --- | --- | --- |
| `open_tabs` | §3.5 的 JSON | 标签顺序 + active；文件只存路径 / 名称 |
| `sidebar_width` | `440` | 资料库宽度 |
| `editor_width_mode` | `limited / full` | 预留，v1 只写 `limited` |

- 不存侧栏开关状态；每次启动收起。
- 不存临时文件正文 / hash；临时内容仍只在内存。

### 10.2 Go service

| 方法 | 职责 |
| --- | --- |
| `store.GetUIState(key)` / `SetUIState(key, value)` | `ui_state` 读写 |
| `system.GetUIState` / `SetUIState` | 暴露给前端 |
| `system.SetTitle(title)` | 更新窗口标题（当前标签 + 未保存 `*`） |
| `notes.OpenCached(id)` | 只读本地缓存，不触网；标签恢复用；未缓存正文时返回索引行（`contentLoaded=false`），由前端显示占位 |
| `notes.Create` 的 `target` | `target='local'` 强制仅本地（登录状态下新建默认本地）；空值沿用旧行为 |

- 不新增后端接口、不改同步协议、不改 `note_local` / `folder_local` / `outbox` 表。
- 改 Go service 签名后执行 `wails3 task bindings`，`bindings/` 随仓库提交。
- `SetUnsaved(any)` 继续使用现有接口，布尔值由标签集合计算。

| 内存 | 标签只存内容字符串；12 × 5MB 最坏约 60MB。若回归明显，非活动且已保存的文件标签可卸载内容、激活时重读 |
| 退出汇总 | 多个 dirty 文件 + 保存失败路径复杂；用统一 `UnsavedDialog`，失败即聚焦该标签并中止 |
| 标签恢复 | 文件只存路径，磁盘可能已变；激活时以磁盘为准，不做跨会话 hash 冲突 |
| 账号切换 | 服务端标签必须关闭，避免旧 scope 数据残留；退出前先 flush |
| 侧栏推挤 | 1024px 下正文约 560px；默认收起、窄窗浮层、随时 `Ctrl+Shift+L` / 顶栏按钮收起 |
| 可发现性 | 顶栏 `☰` + `Ctrl+K` + 起始页最近列表三处入口 |
| 跨库同屏 | v1.2 移除「全部」后本地 / 服务端不再同屏；靠来源徽标、各页签计数、`Ctrl+K` 与起始页最近列表兜底；若后续本地笔记改为自动同步，再评估「最近」视图 |
| 标签栏拥挤 | 88–180px 自适应宽度 + 隐藏原生滚动条；仍超出时横向滚动 / `Ctrl+1..9` / `Ctrl+Tab`；不换行 |
