# AI 能力（AI Features）

> **状态：AI 摘要已实现**；主题 AI 对话见 `docs/theme-ai.md`。
> 范围：管理端文章摘要；共享 AI 连接配置、可选性、失败语义与隐私边界。
> 非目标：对话式摘要、自动摘要（发布路径调用 AI）、笔记摘要、多 provider 路由、重试轮 / 修复轮。

## 0. 决策摘要

| 决策点 | 结论 |
| --- | --- |
| 可选性 | AI 不是任何主流程的依赖：未配置时入口置灰，编辑 / 保存 / 发布照常 |
| 触发方式 | 只在编辑器点击「AI 总结」时调用，不自动触发、不在发布路径调用 |
| 交互形态 | 单轮、无状态：无会话、无记忆、无历史、无流式、无多轮修复 |
| 输入 | 编辑器当前 Markdown **原文**（未保存内容），服务端只做长度保护 |
| 输出 | 一段纯文本，服务端清洗并裁剪到约 80–100 字（句边界 + `…`） |
| 可用性 | `GET /api/admin/ai/status` 首屏获取，`enabled=false` 时按钮置灰 |
| 权限 | 复用 `admin:post:create` / `admin:post:update`，不新增权限节点 |
| 失败 | 503 `AI_UNAVAILABLE` / 502 `AI_FAILED`；前端保留原摘要 |

## 1. 配置

- 连接信息（`base-url` / `api-key` / `model`）唯一来源仍是 `spring.ai.openai.*`，见 `docs/theme-ai.md` §1；本文件不复制具体值。
- 三键任一为空 → `AiEnvironmentPostProcessor` 排除模型装配，`ChatModel` 缺席即“AI 未配置”，启动不受影响。
- 摘要专属编排参数：`simple-notes.ai.summary-timeout`（环境变量 `AI_SUMMARY_TIMEOUT`，默认 `45s`）。输出很短，不与主题 AI 的 300s 共用。
- 输入 / 输出上限是代码常量（`PostSummaryPrompt`），不做成配置，避免出现“摘要可以无限长”的部署。

## 2. 接口

### 2.1 状态

`GET /api/admin/ai/status` → `{ "enabled": boolean }`

- 只表达“连接信息是否齐全”，不返回模型名、网关地址或任何密钥信息。
- 前端据此在首屏把入口置灰（不是隐藏：让用户知道能力存在但未配置）。

### 2.2 摘要

`POST /api/admin/ai/post-summary`

```json
{ "title": "文章标题", "content": "当前编辑器里的 Markdown 原文" }
```

→ `200 { "summary": "……" }`

- 不要求文章先落库：新建文章与未保存修改都可用。
- 服务端**不解析、不改写** Markdown；原文直接进提示词，由模型处理。
- 请求只读：不写 `note`、不写快照、不产生附件；结果只回前端。

## 3. 行为

- **长度保护**：正文超过 30000 字符时，取前 20000 + 后 10000，中间标注“省略 N 字符”；超限不静默丢弃结尾，保证结论段仍可能进入上下文。
- **模型参数**：`temperature=0.3`、`max_tokens=400`、thinking 关闭（`extraBody` 透传，端点忽略未知字段）；OpenCode Go 需要的 `x-opencode-session` 用用户维度哈希填充。
- **输出清洗**：整体 fence 去壳、去“摘要：”前缀、去包裹引号、折叠空白，再按句末标点裁剪到约 80–100 字；确有截断时补 `…`，并清掉悬空的逗号 / 分号 / 冒号。
- **并发**：单用户单并发，独立于主题 AI 的锁；重复请求返回 409。
- **超时**：`summary-timeout` 到期即中断并返回可读错误，避免按钮长时间转圈。

## 4. 不变量

- **不改内容模型**：结果仍写 `note.summary`，发布快照照旧；AI 不自动保存、不自动发布。
- **发布路径不调用 AI**：摘要为空时发布前仍用本地规则提取兜底（去 Markdown 语法 → 取正文开头到句边界 → 补 `…`）；离线 / 未配置 / 网关故障都不阻塞发布。
- **人工终审**：摘要是公开内容，AI 结果只是草稿，发布前必须校对。
- **隐私**：正文会发送到所配置的模型端点；只有用户点击才发生。日志只记标题 / 输入 / 输出字符数、耗时与错误类别，不落正文。
- **密钥边界**：密钥只在服务端环境变量 / 本地值文件；前端只看到 `enabled` 布尔值。

## 5. 失败语义

| 场景 | HTTP | `code` | 前端行为 |
| --- | --- | --- | --- |
| 未配置 / 模型装配缺席 | 503 | `AI_UNAVAILABLE` | 入口置灰，不弹错误 |
| 网关错误 / 鉴权 / 限流 / 超时 / 空输出 | 502 | `AI_FAILED` | toast 可读原因，保留原摘要 |
| 同一用户已有进行中的请求 | 409 | `CONFLICT` | 提示稍后重试 |

规则提取永远可用，不依赖网络与模型；它是 AI 摘要的永久兜底，而不是过渡方案。
