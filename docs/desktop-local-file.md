# 桌面端本地 Markdown：临时编辑、本地笔记与纳入管理（v2.0 设计待实现）

> **状态：v1.1–v1.6 已实现；v2.0 文件夹树与本地 / 云端分离已实现（2026-11-03；Windows 构建 / 单测 / 类型检查；三平台验收待做）**
> 范围：打开本地 `.md` 文件（临时编辑）、免登录的本地笔记、本地 / 云端文件夹树、最近打开、导入为本地 / 云端笔记、已管理笔记导出
> 关联：`docs/desktop-sync.md`（scope / outbox / 冲突）、`docs/content-model.md`（`note` 字段与文件夹模型）、`docs/markdown-dialect.md`（v2 方言）、`docs/desktop-layout.md`（多标签与文档工作台）、`docs/desktop-local-schema.md`（本地迁移）
> 非目标（v2.0）：文件目录 / 工作区、源文件双向绑定、多窗口 / 并排分屏、每标签独立撤销历史、系统「打开方式」关联、批量导入 / 导出、导出 Markdown / ZIP 整库、文件夹拖动排序 / 跨父级移动

> **v1.4 变更**：本地 tab 支持新建 / 改名 / 删除**本地文件夹**（`folder_local.scope_id='local'`，纯本地、不参与同步）；文件夹名在 scope 内唯一、跨 scope 允许同名；空文件夹常驻显示。
> **v1.5 变更**：同步到服务端时，若服务端没有同名文件夹，可直接在同步对话框里**创建**（在线才可用）；同名时仍以服务端 id 为准。含从文件纳入形成的「本地文件」分组。

> **文案约定**：桌面端 UI 统一称「云端」（见 v1.6 落地），本文档沿用「服务端 / 云端」现状描述，二者指同一侧。

## 0. 决策摘要

| 决策点 | 结论 |
| --- | --- |
| 概念区分 | **打开本地文件 = 临时编辑，默认不纳入管理**；「免登录模式」只指在应用内新建 / 管理本地笔记 |
| 临时编辑 | 内存态：不写 SQLite、不进列表、不参与同步；只记录「最近打开」的路径与时间 |
| 登录要求 | 临时编辑、免登录本地笔记均不要求登录；只有同步到服务端要求登录 |
| 启动行为 | **默认进入本地模式（不弹登录页）**：未登录时就是本地 Markdown 编辑器；登录是顶栏可选入口 |
| 保存策略 | **显式保存**（Ctrl+S / 保存按钮）写回源文件；不自动写盘 |
| 导入语义 | **一次性快照**：导入的是当前编辑器内容，之后不再跟踪源文件 |
| 导入位置 | 仅本地（`scope='local'`，免登录）或服务端（active scope + `POST /api/desktop/notes`，需登录） |
| 本地导入的分组 | 默认「未分类」；可选择树中的某个本地文件夹；**不再有内置「本地文件」分组** |
| 云端同步 | 复用离线新建通道；沿用本地笔记 id；移动时只替换为**手选**的云端文件夹 |
| 最近打开 | 记录路径 / 文件名 / 时间，最多 20 条；**全局**（不按账号隔离）；可单条移除 / 清空；不存正文 |
| 打开并纳入 | v1 提供：打开按钮下拉「打开并纳入管理…」，打开后直接弹导入对话框 |
| 同步目标文件夹 | 云端导入 / 同步时只从云端文件夹树中选择，默认「未分类」；**不做名称匹配、不自动创建**；本地文件夹 id 永不发送 |
| 文件夹模型 | 本地与云端**完全分离**：各自一棵树，仅当笔记跨 scope 移动时由用户选择云端文件夹；`parent_id` 两端都落库 |
| 文件夹嵌套 | 支持多级（根为第 1 级，**最深 5 级**）；**同父级下名称唯一**（trim / 大小写不敏感 / ≤64），**跨层级可同名** |
| 文件夹删除 | **有子文件夹时禁止删除**；删除叶子文件夹时其中的笔记移到「未分类」 |
| 文件夹筛选 | 选中某个文件夹时，列表显示该文件夹**及其所有子孙**中的笔记；`noteCount` 按子树聚合 |
| 已管理笔记回退 | **不支持**转回本地文件；提供「导出为 Markdown」生成独立副本，导出后与源笔记无关联 |
| 导出 | 已管理笔记（本地 / 服务端）可导出单篇 `.md`；UTF-8 无 BOM、LF、仅正文（不含 H1）；不改笔记、不参与同步 |
| 同时打开 | **多标签**：可同时打开多个临时文档，并与本地 / 服务端笔记共用标签栏；每个标签独立保存状态，切换不弹保存框，关闭 / 退出时处理；上限 12 个标签 |
| 标签恢复 | 记录打开标签与顺序；文件标签只存路径 / 名称，激活时读盘；不存正文 |
| 退出 | 多个未保存临时文档 → 汇总对话框（全部保存 / 全部放弃 / 取消 / 逐个处理） |
| 撤销 | 单编辑器实例，切换标签清空撤销栈；v1 不保留每标签撤销历史 |
| 文件大小 | 单文件 ≤ **5 MB**（UTF-8 文本）；超过拒绝并提示用外部编辑器 |
| 文件类型 | 仅 `.md`（兼容 `.markdown`）；无扩展名、`.txt` 及其他扩展名一律拒绝 |
| 编码 / 换行 | 仅 UTF-8（去 BOM）；保存时保留原始换行风格（CRLF / LF） |
| 导入标题 | 默认文件名去扩展名，可改，≤ 200 字符（与 `note.title` 一致） |
| 导入类型 | 固定 `NOTE`；博客草稿导入留待后续（发布仍只在 admin） |

## 1. 目标与非目标

### 1.1 目标

1. 不改动既有笔记库，也能快速打开、编辑、保存一个本地 Markdown 文件。
2. 打开的本地文件**默认不被管理**：不写库、不进列表、不同步；需要时再显式「纳入管理」。
3. 不登录也能在应用内新建和管理本地笔记（`scope='local'`）。
4. 纳入管理后与现有笔记行为一致（列表、搜索、编辑、删除），并且能与「应用内新建的本地笔记」区分开。
5. 记住最近打开的文件，减少反复找路径。
6. 已管理笔记可以导出成独立的 `.md` 文件，作为备份 / 外部编辑的副本，但导出后不再受应用管理。

### 1.2 非目标（v2.0）

- 打开整个目录 / 工作区、文件树、多文件搜索；
- 源文件与笔记保持双向同步（外部改动自动合并、文件重命名跟随）；
- 多窗口 / 并排分屏、每标签独立撤销历史；
- 系统文件关联（双击 `.md` 直接进本应用）；
- 批量导入 / 批量导出、ZIP、`front matter` 解析；
- 临时编辑的崩溃恢复（未保存草稿）；
- 把已管理的笔记「转回」本地文件 / 取消纳入（只提供导出副本）；
- 文件夹拖动排序、跨父级移动文件夹、批量移动笔记；
- 本地文件夹与云端文件夹的名称 / 路径自动映射（v1.5 已撤销）。

## 2. 概念与状态

### 2.1 三个容易混淆的概念

| 概念 | 入口 | 是否入库 | 是否同步 | 列表 |
| --- | --- | --- | --- | --- |
| **临时编辑**（打开本地文件） | 「打开文件…」/ 拖拽 / 最近打开 | 否（只记最近路径） | 否 | 否 |
| **免登录模式**（本地笔记） | 启动默认进入；顶栏「登录」可随时接入服务端 | 是，`scope='local'` | 否 | 是，未分类 |
| **纳入管理** | 临时编辑 →「纳入管理…」 | 是 | 仅本地 / 服务端二选一 | 是 |

关键区别：

- **打开本地文件 ≠ 免登录模式**。前者是文件编辑，后者是应用内笔记管理；两者互不依赖。
- 临时编辑在登录 / 未登录 / 免登录模式下都可用；登录后也不会消失。
- 「纳入管理」是一个显式动作：打开文件后可以一直临时编辑，也可以随时纳入。

### 2.2 数据状态

| 状态 | 存储 | 列表可见 | 同步 | 关闭应用后 |
| --- | --- | --- | --- | --- |
| 临时编辑 | 仅内存 + `recent_file` 路径 | 否 | 否 | 内容丢失（未保存已提示） |
| 已管理 · 仅本地（应用内新建） | `note_local`，`scope='local'`，`folder_id` 为空 | 是，标「本地」 | 否 | 保留 |
| 已管理 · 仅本地（文件纳入） | `note_local`，`scope='local'`，`folder_id` 为空或本地文件夹 | 是，归未分类 / 所选本地文件夹 | 否 | 保留 |
| 已管理 · 云端 | `note_local`，`scope=srv:<...>` | 是 | 是（现有协议） | 保留 |

### 2.3 状态机

```text
                    ┌──────────── 关闭 / 放弃 ────────────┐
                    ▼                                    │
[空闲] ──打开文件──> [临时编辑] ──纳入管理──> [已管理] ──同步──> [已同步]
   ▲                    │                        │
   │                    └──另存为（仍是临时）      └──仅本地──> [本地笔记 / 本地文件夹]（可再「同步到云端」）
   └────────────────────── 关闭 ─────────────────────────────┘
```

### 2.4 免登录模式（本地笔记）

- **启动即本地模式**：没有有效会话时不再显示登录页，直接进入主界面的本地形态；登录是可选动作。
  - 只查询 `scope='local'`，不显示服务端笔记；
  - 隐藏同步状态、outbox、发布状态、「管理端发布」；
  - 新建、搜索、编辑、删除、纳入本地笔记全部可用；
  - 顶栏显示「本地模式」+「登录」按钮；空编辑器提供「新建本地笔记 / 打开本地文件…」引导。
- 免登录模式不是新的数据状态：它就是「没有 active scope 时只操作 local scope」的 UI 投影。
- 登录入口是顶栏按钮打开的模态框（复用 `LoginView` 卡片）：登录后关闭对话框并进入服务端同步；取消则继续本地模式。
- 登录后退出免登录模式：服务端索引同步照旧，**本地笔记不会自动推送**；需要用户在笔记内点「同步到服务端」。
- 退出登录后**回到本地模式**（不回到登录页）；`scope='local'` 数据始终保留。

### 2.5 文件夹模型（v2.0）

**本地与云端是两棵完全独立的树**，不做名称 / 路径映射，只在笔记跨 scope 移动时由用户选择目标文件夹。

| 维度 | 本地文件夹 | 云端文件夹 |
| --- | --- | --- |
| 权威表 | 桌面端 `folder_local`，`scope_id='local'` | 后端 `note_folder`（桌面端以 `scope_id=<账号>` 镜像） |
| 主键 | 本地 UUID | 服务端 UUID |
| 层级 | `parent_id`，根为 NULL | `parent_id`，根为 NULL |
| 名称唯一 | 同一父级下唯一（本地部分唯一索引兜底） | 同一父级下唯一（后端唯一索引兜底） |
| 同步 | 永不入 outbox / manifest | 按现有文件夹同步协议镜像到本地 |
| 删除 | 有子级禁止；叶子删除时笔记落「未分类」 | 有子级禁止；叶子删除时笔记落「未分类」 |

约定：

- **嵌套**：根为第 1 级，**最深 5 级**；`Create` 可指定父级，v2.0 **不支持改父级 / 拖动排序**（避免成环与批量搬移的复杂度）；
- **同名规则**：同一父级下唯一（`trim`、大小写不敏感、最长 64 字）；**不同层级允许同名**（`工作/项目A` 与 `生活/项目A` 并存）；
- **删除**：存在未删除的子文件夹时**禁止删除**，提示先处理子级；删除叶子文件夹时，其中的笔记移回「未分类」；
- **计数**：`noteCount` = 该文件夹**子树**（含自身）的未删除 `NOTE` 数量；
- **筛选**：选中某个文件夹时，列表显示该文件夹及其**所有子孙**中的笔记；
- **空文件夹常驻显示**；
- **本地与云端互不影响**：在本地改名 / 建子级不会改变云端；纳入云端时只写所选云端文件夹 id，本地文件夹 id 永不发送；
- 本地文件夹 `dirty` 恒 0，永不进入 `outbox`，也不会被 `UpsertRemoteFolders` 触碰。

```text
本地（scope='local'）            云端（note_folder / scope=<账号>）
├─ 工作                          ├─ 工作
│  ├─ 项目A        ── 选云端文件夹 ──>  │  └─ 项目A
│  └─ 项目B                       └─ 归档
└─ 生活
   └─ 项目A        ← 与「工作/项目A」同名但互不影响
```

### 2.6 移除内置「本地文件」（v2.0）

v1.4/v1.5 用保留 `folder_id='local-files'` 区分「从文件纳入的本地笔记」。v2.0 本地与云端分离后，导入时直接选本地文件夹即可，这个内置桶不再需要，且它是 v1.5 名称映射的依赖，一并撤销。

| 项 | v2.0 行为 |
| --- | --- |
| 导入为「仅本地」 | 默认「未分类」，可在树中选择任意本地文件夹 |
| 已有 `folder_id='local-files'` 数据 | 本地迁移 `0005` 统一改写为 `folder_id=''`（未分类）；开发期脏数据可直接重建 |
| 常量 / 虚拟行 | 删除 `LocalFilesFolderID` / `LocalFilesFolderName` / 前端 `LOCAL_FILES_FOLDER` 与 `Folders()` 内置行 |
| 服务端创建失败回退 | 落「未分类」，不再回退到「本地文件」 |
| 文件来源标识 | 依赖列表行的「本地」来源徽标，不再靠文件夹区分 |

## 3. 交互流程

### 3.1 入口

| 入口 | 说明 |
| --- | --- |
| 顶栏「打开文件…」/ `Ctrl+O` | 主界面、本地模式、临时编辑均可用；默认进入临时编辑 |
| 打开按钮下拉「打开并纳入管理…」 | 打开后直接弹「纳入管理」对话框（v1 提供） |
| 拖拽 `.md` 到窗口 | 窗口开启 `EnableFileDrop`，以带 `data-file-drop-target` 的区域接收；多文件只取第一个 `.md` 并提示 |
| 「最近打开」 | 空编辑器 / 打开按钮下拉展示最近 5–20 条；点击回到临时编辑 |
| 启动默认 | 无会话时直接进入本地模式（不打开文件、不弹登录页） |

打开对话框使用 Wails `Dialog.OpenFile()`，过滤器 `Markdown (*.md;*.markdown)`；拖拽事件为 `common:WindowFilesDropped`（`filenames` + drop target 信息）。路径只来自对话框 / 拖拽 / 最近列表，前端不拼接任意路径。

### 3.2 打开与校验

Go 侧 `files.Open` 依次校验：

1. 解析真实路径（`EvalSymlinks`），拒绝目录 / 设备 / 管道；
2. 扩展名仅 `.md` / `.markdown`（不区分大小写）；无扩展名一律拒绝；
3. 普通文件且大小 ≤ 5 MB；
4. 读取内容，去 UTF-8 BOM；非法 UTF-8 直接拒绝（不做猜测编码）；
5. 记录 `mtimeMs`、`size`、原始换行风格（首个换行是 `\r\n` 还是 `\n`）、内容 SHA-256；
6. 成功后写入 `recent_file`（见 §3.5）；
7. 返回 `{ path, name, content, mtimeMs, size, lineEnding }`。

失败时保持当前文档不变，只提示错误（见 §6）。

### 3.3 临时编辑界面

- 临时文档在编辑区**标签页**中打开，与本地 / 服务端笔记共用标签栏；每个标签独立保存状态。
- 标签 / 文档头显示：文件名（悬停显示完整路径）、`文件` 来源徽标、保存状态（未保存 / 已保存 / 未纳入管理）；操作：`保存`（Ctrl+S）、`另存为…`、`纳入管理…`、关闭标签。
- 不显示同步状态、不显示发布状态、不显示文件夹 / 标签（笔记标签才显示文件夹）。
- 编辑器仍用 Vditor IR + 方言 v2，与现有笔记一致。
- 插图按 `docs/desktop-media.md`：临时文件图片写入同目录 `<stem>.assets/`，正文保留相对路径；纳入本地 / 服务端时分别复制到本地媒体库或上传。
- 切换到其他标签**不弹保存框**：未保存内容留在该标签，标签显示未保存点；关闭该标签时才 `保存` / `放弃` / `取消`。
- 打开另一个文件默认新开标签，不替换当前临时文档；纳入管理成功后用新笔记标签替换当前文件标签。
- 标签上限 12；达到上限提示先关闭；不自动关闭。
- 同时打开多个临时文档时，退出应用显示汇总对话框（全部保存 / 全部放弃 / 取消 / 逐个处理），不再逐个弹窗。

临时文档的内容只存在内存，不写 SQLite；v1.2 会恢复标签路径与顺序，但不恢复未保存正文（仍不做崩溃恢复）。

### 3.4 保存（写回源文件）

```text
Ctrl+S
  → Go: 重新读取源文件
       ├ 不存在              → 提示「文件已被删除」，只允许另存为
       ├ hash 与打开时不一致  → 提示「文件已被其他程序修改」：覆盖 / 另存为 / 重新加载
       └ hash 一致           → 原子写入
  → 写临时文件（同目录）→ 保留原权限 → rename 覆盖
  → 更新 mtime / hash；状态「已保存」；刷新 recent_file 时间
```

- **不自动写盘**（已确认）：避免用户在未预期时改到自己的文件；
- 写回时把内容统一为 LF 再替换成打开时记录的换行风格，避免整文件 diff；
- 原子写入失败 / 文件只读 → 提示改用「另存为」，不留下半写文件；
- 「另存为」使用 `Dialog.SaveFile()`，成功后临时文档路径切换到新文件（原文件不变）；
- 不生成 `.bak` 备份（已确认）。

### 3.5 最近打开

数据表（桌面端 SQLite，`CREATE TABLE IF NOT EXISTS`，不涉及 Flyway）：

```sql
create table if not exists recent_file (
    path      text primary key,   -- 绝对路径（解析符号链接后）
    name      text not null,      -- 文件名，用于展示
    opened_at integer not null    -- epoch ms；打开 / 保存时更新
);
```

- 成功打开或保存后 upsert；按 `opened_at` 倒序保留 **20 条**，其余删除；
- 只存路径 / 文件名 / 时间，**不存正文、不存 hash、不存编辑状态**；
- 全局唯一，不按账号隔离（本地文件与账号无关，已确认）；
- UI：打开按钮下拉 / 空编辑器列出最近项；支持「从最近列表移除」与「清空最近记录」；
- 文件已删除 / 无权限：点击时提示，并允许从列表移除；
- 临时编辑关闭后，最近项仍在（这是「最近打开」而非「会话恢复」）。

### 3.6 纳入管理

点击「纳入管理…」弹出小对话框：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| 标题 | 文件名去扩展名 | 可改；空则「未命名」；> 200 字符提示修改（不静默截断） |
| 目标 | 仅本地 | `仅本地` / `服务端（当前账号）`；未登录时服务端选项置灰 |
| 文件夹 | `未分类` | 本地目标：本地文件夹树；云端目标：云端文件夹树。两边都默认「未分类」，不共享选择 |

对话框底部固定说明：

> 纳入管理会复制**当前编辑器内容**建立一篇笔记，源文件不会被继续跟踪；之后的修改只在应用内保存。

- 未登录：`仅本地` 可用（免登录模式的核心能力）；`服务端` 置灰并提示「登录后可用」。
- 导入内容即当前编辑器内容（含未保存改动），不是磁盘上的旧版本。
- 每次导入生成新的 UUID，允许同一文件多次导入（产生多篇独立笔记）。

### 3.7 导入为「仅本地」

```text
notes.ImportFile({ title, content, target: "local", folderId })
  → note_local(scope='local', id=UUID, kind='NOTE',
               folder_id='' | 本地文件夹, content_loaded=1, dirty=0)
  → 刷新列表并选中该行（归入所选文件夹）
  → 用新笔记标签替换当前文件标签，编辑器切换为已管理笔记（其他标签不受影响）
```

- 全程不要求登录、不访问网络；
- 仅本地笔记沿用现有语义：永不入 outbox、切换账号仍可见、删除只删本地；
- `folderId` 为空 → 「未分类」；未知 / 已删除的本地文件夹也收敛为「未分类」；
- 用户可在笔记里把文件夹改为其他本地文件夹或「未分类」，或后续「同步到云端」。

### 3.8 导入为「服务端」与后续同步

```text
notes.ImportFile({ ..., target: "server", folderId })
  1. 要求已登录（active scope + token）；未登录直接报错并提示先登录
  2. 先落 note_local(activeScope, dirty=1)
  3. POST /api/desktop/notes（body 带本地 UUID；folderId 为所选云端文件夹或 null）
       ├ 200/201 → MarkNoteSynced(version) → 「已同步」
       ├ 409     → GET 详情：hash 一致则对齐版本；不一致进入现有冲突流程
       ├ 401/5xx/网络错误 → outbox(create) → 「离线（待同步）」
       └ 其他 4xx → 保留本地并提示错误
```

- 复用 `notes.Create` 已有的「客户端 UUID + outbox + 409 对齐」路径，不新增接口；
- 已存在的「仅本地」笔记，在列表 / 编辑器提供「同步到服务端」动作：

```text
notes.PromoteLocal(id, folderId)
  → 读取 scope='local' 行（必须 content_loaded）
  → folderId 为空则落「未分类」；否则必须是当前账号的云端文件夹 id
  → store.MoveNoteScope('local' → activeScope)（scope_id 改写，folder_id 更新，dirty=1）
  → POST /api/desktop/notes（id 不变）
  → 成功 / 409 / 离线处理同上
```

- 移动后 `GetNoteAny` 不再命中 local，列表也不会出现重复项；
- 目标文件夹**只由用户在云端文件夹树中选择**：不按名称匹配、不自动创建、不读取本地文件夹结构；
- 本地文件夹 id 永不发送；服务端同步后 `kind` 仍为 `NOTE`；发博客仍走 admin 的「转为博客草稿 → 发布」。

### 3.9 导出为 Markdown（已管理笔记）

- 入口：文档头 `⋯` 菜单「导出…」；列表项菜单「导出为 Markdown…」。
- 内容取当前笔记的 `content`：未缓存的服务端笔记先走现有 `Open` 拉取；离线且未缓存时提示先联网打开。
- 默认文件名 = 标题做文件名安全化（去掉 `\ / : * ? " < > |` 与控制字符，去首尾空格 / 点，最长 100 字符）+ `.md`；标题为空用「未命名」。
- 使用 `Dialog.SaveFile()` 选择目标；覆盖确认由系统对话框负责。
- 写 UTF-8 无 BOM、LF；正文原样导出，**不额外插入标题 H1**（标题由默认文件名保留）。
- 使用临时文件 + rename 原子写；失败提示，不产生半写文件。
- 导出**不改变**笔记：不推进 `version`、不置 `dirty`、不进 outbox、不写 `recent_file`。
- 导出的文件与应用不再关联，可再用「打开文件」临时编辑；若要重新纳入会生成新笔记（允许重复）。
- 已管理笔记**不提供**「转回本地文件 / 取消纳入」，只提供导出副本。
- v1 只支持**单篇导出**，不做批量 / 整库 ZIP。

### 4.7 后端与同步协议（v2.0，已实现）

- **迁移**：新增后端 Flyway 脚本（实现时按当时最新版本 +1，当前为 `V18__folder_tree.sql`）：
  - `alter table note_folder add column parent_id varchar(36)`；
  - `drop index uk_note_folder_owner_name` → 新建 `uk_note_folder_owner_parent_name (owner_id, coalesce(parent_id, ''), lower(name)) where delete_flag = 0`；
  - 历史文件夹 `parent_id` 保持 NULL（根）。
- **深度 / 成环**：创建时向上回溯父链，超过 5 级拒绝；v2.0 不支持改父级，因此无需成环检测（保留校验函数供未来使用）。
- **删除**：`delete` 前统计未删除子级；> 0 返回 409「请先删除子文件夹」；叶子文件夹按现有逻辑把笔记移到未分类（软删除文件夹）。
- **筛选语义**：`folderId` 表示「该文件夹及所有子孙」；后端与桌面端保持同一语义。
- **同步协议**：文件夹 manifest 增加 `parentId`；`UpsertRemoteFolders` 按平铺列表写入，不再假设单层；远端删除的文件夹不会留下子级（服务端禁止删除非空）。
- **不引入名称 / 路径映射**：笔记跨 scope 时只写用户选中的云端文件夹 id。

```sql
alter table note_folder add column parent_id varchar(36);

    on note_folder (owner_id, coalesce(parent_id, ''), lower(name))

```

```sql

    on folder_local (scope_id, coalesce(parent_id, ''), lower(name))
    where scope_id = 'local';

 where scope_id = 'local' and folder_id = 'local-files';
```

## 5. 边界与安全

| 项 | 规则 |
| --- | --- |
| 大小 | > 5 MB 拒绝；提示用外部编辑器，不截断 |
| 编码 | 仅 UTF-8；BOM 去除；非 UTF-8 拒绝（避免乱码写回） |
| 扩展名 | 仅 `.md` / `.markdown`；无扩展名、`.txt` 等拒绝 |
| 换行 | 记录原风格，保存时还原；无换行时按 LF |
| 路径 | 只接受对话框 / 拖拽 / 最近列表返回的绝对路径；解析符号链接后操作真实文件 |
| 只读 / 占用 | 写失败不重试、不降级为直接覆盖；提示另存为 |
| 外部修改 | 保存前比对内容 hash；不一致必须用户确认 |
| 文件被删 | 不自动重建；只能另存为；最近项可手动移除 |
| 临时内容 | 每个标签独立内存态；不落库、不写日志、不进 outbox、不参与搜索；仅最近路径与标签顺序落库 |
| 多标签 | 单编辑器实例；切标签清空撤销栈；上限 12 个；未保存内容按标签隔离 |
| 标签恢复 | 只恢复路径 / 顺序 / 当前标签；文件激活时读盘；不存正文 / hash |
| 最近记录 | 只存路径 / 文件名 / 时间，可单条移除 / 清空；不按账号隔离 |
| 本地文件夹 | `folder_local(scope_id='local')`，本地 UUID；可嵌套（`parent_id`）；不入 outbox、不参与 manifest / 同步；删除叶子文件夹时笔记移回「未分类」 |
| 文件夹树 | 两端都支持嵌套，根为第 1 级、最深 5 级；同父级唯一、跨层级可同名；v2.0 不支持改父级 / 拖动排序 |
| 文件夹删除 | 有子文件夹时禁止删除；提示先删除或移走子级 |
| 文件夹筛选 / 计数 | 选中文件夹 = 该文件夹及所有子孙；`noteCount` 按子树聚合 |
| 本地 / 云端对应 | **完全分离**：不做名称 / 路径匹配、不自动创建；纳入云端时只写用户选中的云端文件夹 id |
| 移除 `local-files` | 不再有内置「本地文件」分组；迁移把既有 `folder_id='local-files'` 改为未分类 |
| 导出 | 只读笔记内容：不推进 `version`、不置 `dirty`、不进 outbox；UTF-8 无 BOM、LF；默认文件名做安全化 |
| 已管理回退 | 不支持转回本地文件；导出的是独立副本，与应用无关联 |
| 大载荷 | 正文走 binding（单文件 ≤ 5 MB，仅打开 / 保存时传输，不按键传输）；多标签下仍按单文件限制；图片 / 附件不走 IPC，走 Wails 同源 `/__media/import` 流式接口（`docs/desktop-media.md`） |
| 图片 | 临时文件图片存 `<stem>.assets/`，正文相对路径；另存为复制并改写；不写 `file://` / base64 |
| 免登录模式 | 启动默认即此模式；不读取令牌、不调用 `/api/**`；只访问本地 SQLite |
| 平台 | 对话框 / 拖拽需 Windows / macOS / Linux 实机验收（Linux 走 GTK 对话框） |

## 6. 错误与提示

| 场景 | 提示 |
| --- | --- |
| 非 Markdown / 无扩展名 | 只支持打开 `.md` / `.markdown` 文件 |
| 超过 5 MB | 文件超过 5 MB，请用外部编辑器打开 |
| 非 UTF-8 | 文件不是 UTF-8 编码，暂不支持打开 |
| 文件被外部修改 | 文件已被其他程序修改：覆盖 / 另存为 / 重新加载 |
| 文件被删除 | 文件已被删除，请使用「另存为」；可从最近列表移除 |
| 无写权限 | 无法写入该文件，请使用「另存为」 |
| 未登录选择云端 | 请先登录后再同步到云端；可先保存为「仅本地」 |
| 文件夹重名 | 已存在同名文件夹（同一父级下）；大小写 / 首尾空格视为同名 |
| 文件夹名过长 | 文件夹名称最长 64 个字符 |
| 超过层级上限 | 文件夹最多支持 5 级 |
| 删除非空文件夹 | 请先删除子文件夹（或把子文件夹移走） |
| 删除叶子文件夹 | 已删除，笔记已移到未分类 |
| 免登录模式新建失败 | 显示本地保存错误（不涉及网络提示） |
| 云端导入失败 | 保留在本地，可稍后重试 / 重试按钮（outbox） |
| 导出时笔记未缓存且离线 | 该笔记尚未缓存，请联网打开后再导出 |
| 导出写入失败 | 无法写入目标文件，请换一个位置；不留半写文件 |

## 9. 已确认范围（2026-11-03 v2.0）

| 项 | 结论 |
| --- | --- |
| 打开本地文件与本地笔记 | **两种能力分开**：打开文件默认临时编辑、不纳入管理；应用内新建才是本地笔记 |
| 本地 / 云端文件夹 | **两个独立命名空间**，各自一棵树；不按名称 / 路径映射，纳入云端时由用户选择目标文件夹 |
| 本地导入的分组 | 默认「未分类」，可手选本地文件夹；**移除内置「本地文件」** |
| 文件夹嵌套 | **两端都支持**；根为第 1 级、最深 **5 级**；同父级唯一（trim / 大小写不敏感 / ≤64），跨层级可同名 |
| 文件夹删除 | **有子文件夹时禁止删除**；删除叶子文件夹时笔记挪到「未分类」；空文件夹常驻显示 |
| 文件夹筛选 / 计数 | 选中父文件夹 = 该文件夹及所有子孙；`noteCount` 按子树聚合 |
| 文件夹移动 | v2.0 **不支持**改父级 / 拖动排序 |
| 临时编辑是否自动写回 | **默认关**，只保留显式保存 |
| 未登录能否仅本地管理 | **能**：启动默认即本地模式，只操作 `scope='local'`；登录是顶栏可选入口 |
| 单文件上限 | **5 MB** |
| 文件类型 | 允许 `.md`（兼容 `.markdown`）；**不允许无扩展名**，也拒绝 `.txt` 等 |
| `.bak` 备份 | **不需要** |
| 导入类型 | 固定 `NOTE` |
| 最近打开 | **记录**：最多 20 条，只存路径 / 文件名 / 时间；**全局**，不按账号隔离 |
| 打开并纳入 | **v1 提供**：打开按钮下拉「打开并纳入管理…」；默认仍是纯临时编辑 |
| 同步目标文件夹 | **只从云端文件夹树手选**，默认「未分类」；不做同名匹配、不自动创建；本地文件夹 id 永不发送 |
| 已管理笔记回退 | **不提供**转回本地文件；提供「导出为 Markdown」，导出副本与笔记无关联 |
| 导出内容 | **不包含标题 H1**：正文原样导出，标题由默认文件名保留 |
| 导出的云端笔记 | 未缓存时**自动拉取**；离线且未缓存则提示先联网 |
| 批量导出 | **暂不需要**，v1 只支持单篇导出 |
| 多标签 | **支持**：文件 / 本地 / 云端笔记统一标签；上限 12；切换不弹窗；退出汇总处理 |
| 标签恢复 | 恢复顺序与当前标签；文件只存路径、激活时读盘；不存正文 |
| 撤销栈 | 切标签清空（单编辑器实例）；不做每标签撤销历史 |

> 本版范围已全部确认；实现中若出现新决策，回到本文档补记并升版本。
